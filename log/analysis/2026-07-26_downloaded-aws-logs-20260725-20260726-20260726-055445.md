## エグゼクティブサマリー

1. **インフラは概ね安定** — ユーザー向け HTTP 5xx は **0 件**。Gunicorn SIGTERM 50 件・タスク起動 32 回は ECS ローリングデプロイ/リサイズ（7/26 04:00 UTC 密集）の正常ノイズ。Neon DB は SSL 切断 30 回すべて 1 試行で自動復旧。

2. **AWS 連携の設定ミス** — Bedrock Medicine KB `30BCEJCJHA` への `Retrieve` が AccessDenied（403×3）。Comprehend Medical が `ap-northeast-1`（非対応リージョン）へ接続試行し DNS 失敗 36 件。同一時間帯（03:32–03:39 UTC）に Redis タイムアウト 2 件。

3. **会話品質の最大課題は比較 Q&A ルーティング** — 「イブとロキソニンの違い」系の質問が `layer1_side_effect_qa` gate に吸収され、副作用 CSV ダンプが返る（3 セッション横断）。ヒューリスティック `side_effect_qa_mishandled`（critical×3）は LLM 再判定で **false positive**（副作用 Q&A 本文は妥当）。

5. **性能は構造的ボトルネック継続** — web 全 16 ターン median **13.9s**、p95 **37.4s**。推奨経路 37–42s は LLM 以外の非計測区間 ~20–30s。Concierge 初回 security 外れ値 ~7s。

6. **LINE Webhook トラフィックなし** — 全 6 セッション `channel: web`。staging LINE E2E は別途必要。

7. **メタ/about セッションは良好** — `1785042744917457911486`（11 ターン）は Concierge 経路で GCP/AWS 差分・changelog・システム説明を一貫回答。
