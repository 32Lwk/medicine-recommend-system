## 6. 根本原因

1. **観測ギャップ（trace-only）**  
   全9ターン `response_missing: true`。Concierge / counseling 経路で `counseling_detail` が出力されておらず、応答品質・トーン・拒否メッセージの妥当性をログから検証不能。

2. **triage subcategory の不安定さ（店舗 off-topic 質問）**  
   「トイレどこ？」「映画館どこ？」「トイレットペーパーどこ？」の3問で、映画館のみ `general_other`、他2問は `store_inquiry`。同一意図クラスタ内の分類ブレ。

3. **intent_router shadow と primary triage の乖離（ターン8）**  
   shadow が `Security/aggressive_input` (confidence 0.99) を返したが triage は `Other/general_other` のまま。`dispatch_none_orchestrator_fallback` で Security router 結果が捨てられ OtherHandler にフォールバック。

4. **パフォーマンス**  
   safety_gate が 4–8s/ターン。ターン8は counseling 多段 LLM で 18.7s。ユーザー体感遅延リスク。

5. **セッション性質**  
   メタ質問→ off-topic 店舗→侮辱のプロbing。本番ユーザーよりテスト／探索的利用の可能性が高い。
