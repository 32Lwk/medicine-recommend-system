   DB / LLM 入力用 `conversation_history` には `sage_qa` 等の render キーではなく `diagnosis.message` または `feedback_context.ai_response` の平文を保存。フォロー QA の文脈維持に必須。

3. **フォロー QA プロンプト強化**  
   「S はついていません／ついていました」等の短い訂正は、直前の医薬品名（ロキソニン）文脈で解釈する指示を `medicine_qa/focus_llm` および followup 応答生成に追加。

### 優先度 中

4. **RAG スコープ制限**  
   同一セッションで直前ターンに特定医薬品（ロキソニン）が確定している場合、参照候補をその製品ファミリーに優先スコープ。

   医薬品名・剤形キーワードを含む入力では「お話しできて良かったです」系の終了テンプレを抑制。

6. **ターン 8 パフォーマンス計測**  
   `product_image_fast_path` / `medicine_information_qa` 区間（~24 s）に breakdown ステップを追加し、遅延要因を可視化。
