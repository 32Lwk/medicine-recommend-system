**原因分析**

1. `try_dev_error_trigger("client_error")` は `_save_user_message_only` のみ実行し **session.messages に bot を追加しない**（`chat_dev_triggers.py` L357–369）。

3. bot 追記なし → `response_missing` → `append_system_error_notice` で **system_error Sage カード**を強制追加（L183–188）。
4. 結果、counseling_detail には system_error 文言が記録され、dev プレビュー JSON の `error: true` 意図がフロント/UI ログ上は埋没。
