## 改善提案

### P0（UX / インフラ）

1. `handle_medicine_information_qa` の 120s timeout 後、バックグラウンドスレッドが継続してセッション更新していないか調査。timeout 時は処理中断または非同期ジョブ化。
2. `product_image_fast_path_*` の計測名を比較 QA でも使っている点を整理し、比較意図時は別 timeout / 別経路を検討。
3. 比較 QA の p95 レイテンシ SLA（例: 30s）を設定。

### P1（内容）

1. 3剤比較テンプレート: バファリンA を「中間」ではなく「アスピリン系＋制酸配合の NSAIDs」と明記。
2. 併用注意: ユーザー提示薬名に合わせた例（ロキソプロフェン+アスピリン）を優先。
3. ロキソニンS 言及時に第1類・薬剤師相談の一文を追加。

### P2（ログ）

1. medicine_qa ターンに `input_labels: general` のみ — `medicine_comparison` 等のラベル付与で分析精度向上。
2. intent_router dispatch ログを ECS エクスポートに含める。
