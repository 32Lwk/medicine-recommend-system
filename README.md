## 📋 概要

このシステムは、症状を入力すると適切な市販薬を提案し、薬の飲み合わせや注意点についてアドバイスを提供するAIシステムです。ルールベースとAIを組み合わせたハイブリッド推奨システムを採用し、安全性と監視機能を大幅に強化した最新版です。

- **症状特異性ペナルティ**: 単一症状時に複合薬（総合感冒薬など）にペナルティを適用し、特化薬を優先

- **症状適合度の強化**: 同義語も含めた症状マッチングで局所治療薬や総合感冒薬を適切に評価

- **リスク成分フィルタリング**: ヒマシ油、センナ、アスピリンなどの高リスク成分を検出し、単一症状時は除外、複数症状時は減点方式で対応
- **曖昧症状の質問生成**: 腹痛、頭痛など曖昧な症状に対して具体的な質問を自動生成（critical_questions優先表示）

### ルールベーススコアリング（2025年11月1日更新）

```
合計スコア = 
  症状適合度 (0-1.0) × 0.35
  + 効能特異性 (0-1.0) × 0.25
  + 年齢適合性 (0-1.0) × 0.20
  + 用法簡便性 (0-1.0) × 0.05
  - 副作用リスク (0-1.0) × 0.20
  - 相互作用リスク (0-1.0) × 0.10
  - 症状特異性ペナルティ (0～-0.3)
  - リスク成分ペナルティ (0～-0.5)
```

#### スコア要素の詳細
- **症状適合度**: ユーザーの症状と医薬品の効能の適合度（重み: 0.35）
- **効能特異性**: 医薬品の効能が症状に対してどれだけ特異的か（重み: 0.25）
- **年齢適合性**: ユーザーの年齢と医薬品の年齢制限の適合度（重み: 0.20）
- **用法簡便性**: 医薬品の用法・用量の簡便性（重み: 0.05）
- **副作用リスク**: 医薬品の副作用のリスクレベル（重み: -0.20）
- **相互作用リスク**: 他の薬との相互作用のリスクレベル（重み: -0.10）
- **症状特異性ペナルティ**: 単一症状時に複合薬（総合感冒薬など）に適用されるペナルティ（効能特異性に応じて-0.3～-0.05）
- **リスク成分ペナルティ**: ヒマシ油、センナ、アスピリンなど高リスク成分含有時のペナルティ（-0.5～0）

## 医薬品推奨アルゴリズム詳細

### ⚠️ 安全性確保のための5層防御システム

本システムは、誤った推奨や不適切な推奨を防ぐために、以下の5層の防御機構を実装しています：

1. **Layer 1: 入力検証（セキュリティ）** - リスクスコア80以上で即停止
2. **Layer 2: NLU（症状抽出）** - 症状未検出で推奨中断
3. **Layer 3: 禁忌チェック（エスカレーション）** - 乳児・幼児・妊娠中・授乳中で即停止
4. **Layer 4: スコアリング** - アレルギー検出でスコア0.0（完全除外）
5. **Layer 5: 最終判定** - 上位3件の推奨のみ表示

**重要**: いずれかの層で異常が検出された場合、即座に推奨プロセスを停止または中断し、医師相談を促します。

### 1. システム全体の推奨プロセス

#### 1.1 入力検証とセキュリティチェック
1. **セキュリティ検証** (`security_validator.py`)
   - ユーザー入力を `validate_user_input` で検証
   - リスクスコア計算（0-100）
   - ブロック判定（Phase 3以降、スコア80以上で医薬品推奨を完全停止）

2. **入力サニタイズ**
   - XSS対策のためのテキストサニタイズ
   - プロンプトインジェクション攻撃の検出とブロック

#### 1.2 言語検出と多言語対応
1. **言語検出** (`medicine_logic.py` - `detect_language`)
   - 日本語、英語、中国語、韓国語の自動検出
   - 言語に応じた属性抽出プロンプトの生成

### 5. スコアリングアルゴリズム（2025年11月1日更新）

#### 5.1 スコアリングウェイト（最適化版）
```python
ENHANCED_SCORING_WEIGHTS = {
    "症状適合度": 0.35,      # 0.30から増加（最重視）
    "効能特異性": 0.25,      # 0.20から増加
    "副作用リスク": -0.20,   # -0.40から緩和（妥当な範囲に調整）
    "年齢適合性": 0.20,      # 0.15から増加
    "用法簡便性": 0.05,
    "相互作用リスク": -0.10, # -0.20から緩和

# 新規追加・改善（2025年11月7日更新）
- 症状特異性ペナルティ: 単一症状時に複合薬に適用（効能特異性に応じて-0.3～-0.05）
- リスク成分ペナルティ: 高リスク成分含有時に適用（-0.5～0）
- 効能特異性に応じたペナルティ緩和: 特異性が高いほどペナルティを軽減（分散拡大）
- 複数症状（例: のどの痛み＋発熱）では総合感冒薬を優先（+0.25ボーナス）、解熱鎮痛薬は軽微なペナルティ（-0.05）
- 喉症状で液剤シグナル（シロップ・内服液・ドリンク等）が検出された場合は+0.22のボーナスを付与
- 剤形多様性: 同スコアの場合、液剤を1件含めるよう優先選択
```

#### 5.2 各スコアの計算方法

**1. 症状適合度** (`calculate_symptom_match_score`)
```
症状スコア = Σ(症状辞書の重み) / 症状数
- 効能効果テキストに症状名が含まれるかチェック
- 各症状の重み（0.7-0.95）を使用
```

**2. 効能特異性** (`calculate_efficacy_specificity_score`)
```
特異性スコア = (症状マッチ数 / 症状数) × (1.0 - 長さペナルティ × 0.3)
- 効能効果テキストに症状がどれだけ特化しているか
- 100文字を基準とした長さペナルティ
```

**3. 年齢適合性** (`calculate_age_fit_score`)
```
年齢スコア:
- 15歳以上: 1.0（問題なし）
- 7-15歳: 0.7（減点）
- 7歳未満または15歳未満制限: 0.0（除外）
```

**4. 用法簡便性** (`calculate_usage_convenience_score`)
```
服用回数によるスコア:
- 1日1回: 1.0
- 1日2回: 0.8
- 1日3回: 0.6
- 1日4回: 0.4
- それ以上: 0.2
```

**5. 副作用リスク** (`calculate_side_effect_risk_score`)
```
副作用データ（medicine_side_effects.csv）から計算:
- 副作用レベル「高」: -0.8
- 副作用レベル「中」: -0.5
- 副作用レベル「低」: -0.2
- 禁忌条件に該当: 2倍（リスク倍増）
- 妊娠中・授乳中: 1.5倍
```

**6. 相互作用リスク** (`calculate_interaction_risk_score`)
```
相互作用データ（medicine_interactions.csv）から計算:
- 相互作用レベル「高」: -0.8
- 相互作用レベル「中」: -0.5
- 相互作用レベル「低」: -0.2
- 相互作用検出時は最大-0.5に制限（元-0.05から4倍増）
```

**7. 症状特異性ペナルティ** (`calculate_symptom_specificity_penalty`)（最適化版）
```
単一症状時に複合薬（総合感冒薬など）に適用されるペナルティ:
- 効能特異性 < 0.8: ペナルティ -0.3（従来通り）
- 0.8 ≤ 効能特異性 < 0.95: ペナルティ -0.15（50%緩和）
- 効能特異性 ≥ 0.95: ペナルティ -0.05（83%緩和）
- 症状カテゴリ間優先表（SYMPTOM_CATEGORY_PENALTY）で柔軟に設定
- 複数症状の場合はペナルティなし
- 効果: 効能特異性が高い医薬品が適切に評価され、スコア分散が拡大
```

**8. リスク成分ペナルティ**（新規追加）
```
高リスク成分含有時のペナルティ:
- アスピリン: -0.5（インフルエンザリスク時は除外）
- ヒマシ油: -0.4（単一症状時は除外）
- センナ: -0.3（単一症状時は除外）
- コデイン: -0.4（依存性リスク）
- トラマドール: -0.4（依存性リスク）
- 単一症状時は除外、複数症状時は減点方式で警告表示
```

#### 5.3 アレルギー・相互作用チェック
**アレルギー照合** (`check_allergy_contraindication`)
```
1. 成分名正規化辞書を使用（INGREDIENT_NORMALIZATION）

### 9. 誤った推奨を防ぐための安全機構（2025年11月1日更新）

#### 9.0 最新の安全機構追加（2025年11月1日）

**1. インフルエンザ検出とアスピリン除外**
- 高熱（38.5度以上）+ 複数の風邪症状（2つ以上）でインフルエンザリスクを検出
- インフルエンザリスク時はアスピリン含有医薬品を自動除外（ライ症候群リスク回避）
- パーソナライズドアドバイスにインフルエンザの可能性を記載

**2. 症状特異性ペナルティ**
- 単一症状（例：発熱のみ）時に複合薬（総合感冒薬など）にペナルティ（-0.3）を適用
- 症状カテゴリ間優先表（SYMPTOM_CATEGORY_PENALTY）で柔軟に設定
- 特化薬（解熱鎮痛薬など）を優先的に推奨

**3. リスク成分フィルタリング**
- ヒマシ油、センナ、アスピリン、コデイン、トラマドールなどの高リスク成分を検出
- 単一症状時はリスク成分含有医薬品を除外
- 複数症状時は減点方式（-0.4～-0.5）で対応し、警告メッセージを表示

**4. 特殊用途医薬品フィルタリング**
- 食あたり専用、便秘限定、腸内容物排除など特殊用途医薬品を検出
- 症状が特殊用途と完全に一致しない場合は除外

**5. 曖昧症状の質問生成**
- 腹痛、頭痛、咳などの曖昧な症状に対して具体的な質問を自動生成
- critical_questionsとして追加質問と統合して表示（推奨 → アドバイス → 質問の順）
- 曖昧症状が検出されても推奨を継続（症状が検出されていない場合のみ推奨を中断）

**6. 検証関数の分離**
- `_recheck_risk_ingredients`: リスク成分の再チェックと警告追加
- `_check_influenza_compatibility`: インフルエンザ適合性チェック
- `_finalize_recommendations`: 最終推奨の確定処理（責務統合）
- スコアが0.5未満の候補に警告を付与

**7. スコアリング後の再検証**
- 推奨後の検証処理（_finalize_recommendations）で最終チェック
- リスク成分警告の強化（特に単一症状時）
- インフルエンザ適合性の再確認
- 低スコア候補の警告表示

#### 9.1 多層安全性チェック
```
Layer 1: 入力検証（セキュリティ）
  ↓ リスクスコア80以上で即停止

#### 12.2 二段階スコアリング（2025年11月7日更新）
**高速化と精度の両立**:
- **簡易スコアリング**: 症状マッチ（50%）+ 効能特異性（30%）+ 年齢適合性（20%）+ 症状特異性ペナルティを計算
  - 複数症状時の薬効調整を簡易スコアにも適用（風邪薬 +0.25、解熱鎮痛薬 0.0）
- **上位N×250件の選別**: 簡易スコアで上位750件（N=3の場合）を選別（異なる薬効カテゴリの多様性確保）
- **閾値ベースの選別**: 簡易スコアが0.3以上の候補も含める（高スコア候補の漏れを防止）
- **詳細スコアリング**: 選別された候補のみに詳細スコアリングを実行
- **剤形多様性**: 液剤を優先的に1件含めるよう選択
- **効果**: 効能特異性が異なる薬効カテゴリ間でも適切な比較を実現しつつ、高速性を維持

**処理フロー**:
```
1. 全候補に対して簡易スコアリング（症状適合度×0.5 + 効能特異性×0.3 + 年齢適合性×0.2 + 症状特異性ペナルティ）
2. 簡易スコアで上位N×250件を選別（または簡易スコア0.3以上の候補）
3. 選別された候補のみに詳細スコアリング（6要素）を実行
4. 成分多様性と剤形多様性を考慮して上位N件を選択（液剤を優先的に1件含める）
```

## トラブルシューティング

### APIキーが認識されない場合
1. 環境変数が正しく設定されているか確認
2. `.env`ファイルが正しい場所にあるか確認
3. ファイルの文字エンコーディングがUTF-8か確認
4. プログラムを再起動して環境変数を再読み込み

### Webアプリケーションが起動しない場合
1. Flaskがインストールされているか確認
2. ポート5000、5001が使用されていないか確認
3. ファイアウォールの設定を確認

### CSVファイルが読み込めない場合
1. ファイルが正しい場所にあるか確認
2. ファイルの文字エンコーディングを確認
3. ファイルの権限設定を確認

### エラーが発生した場合
1. `app.log`ファイルでエラーの詳細を確認
2. `log/recommendation_log.jsonl`で推奨履歴を確認
3. デバッグアプリ（`http://localhost:5001`）で状態確認
4. エラーメッセージが永続表示される場合は手動で閉じる

### 502 Bad Gatewayエラーが発生した場合
1. サーバーのメモリ使用量を確認
2. ワーカープロセスの状態を確認
3. タイムアウト設定を確認（現在300秒に設定）
4. ログでワーカーの再起動状況を確認

### セッション管理エラーが発生した場合
1. ブラウザのCookieをクリア
2. ページを再読み込み
3. 新しいセッションで再試行
4. セッション管理の自動復旧機能により自動的に復旧される場合がある

### 使用上の注意が表示されない場合
1. ChatGPT APIキーが正しく設定されているか確認
2. ネットワーク接続を確認
3. ブラウザのコンソールでエラーメッセージを確認
4. 使用上の注意はChatGPTで自動生成されるため、API制限に注意

### スマホでの表示が崩れる場合
1. ブラウザのキャッシュをクリア
2. ページを再読み込み
3. iPhone Safariの場合は「デスクトップ版Webサイトを表示」をオフに設定

### 質問応答が動作しない場合
1. 質問キーワード（「ですか」「でしょうか」「ドーピング」など）が含まれているか確認
2. セッションが正常に保存されているか確認
3. 管理画面でAI応答の表示を確認
