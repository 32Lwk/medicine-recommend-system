# チャット型医薬品相談ツール - 統合ドキュメント

## 📋 概要

このシステムは、症状を入力すると適切な市販薬を提案し、薬の飲み合わせや注意点についてアドバイスを提供するAIシステムです。ルールベースとAIを組み合わせたハイブリッド推奨システムを採用し、安全性と監視機能を大幅に強化した最新版です。

## システムアーキテクチャ

### 推奨フロー

```
ユーザー入力 → 症状分析（NLU）
                ↓
        ┌──────────┴──────────┐
        ↓                     ↓
   ルールベース推奨        ChatGPT推奨
   (全医薬品種類対応)      (フォールバック)
        ↓                     ↓
        └──────────┬──────────┘
                   ↓
         安全性チェック（年齢・妊娠・重症度）
                   ↓
         使用上の注意自動生成（ChatGPT）
                   ↓
         セッション更新 + 推奨結果
```

### ルールベーススコアリング

```
合計スコア = 
  症状適合度 (0-1.0)
  + 効能特異性 (0-1.0)
  + 年齢適合性 (0-1.0)
  + 用法簡便性 (0-1.0)
  - 副作用リスク (0-1.0)
  - 相互作用リスク (0-1.0)
```

#### スコア要素の詳細
- **症状適合度**: ユーザーの症状と医薬品の効能の適合度
- **効能特異性**: 医薬品の効能が症状に対してどれだけ特異的か
- **年齢適合性**: ユーザーの年齢と医薬品の年齢制限の適合度
- **用法簡便性**: 医薬品の用法・用量の簡便性
- **副作用リスク**: 医薬品の副作用のリスクレベル
- **相互作用リスク**: 他の薬との相互作用のリスクレベル

## トラブルシューティング

### APIキーが認識されない場合
1. 環境変数が正しく設定されているか確認
2. `.env`ファイルが正しい場所にあるか確認
3. ファイルの文字エンコーディングがUTF-8か確認
4. プログラムを再起動して環境変数を再読み込み

### Webアプリケーションが起動しない場合
1. Flaskがインストールされているか確認
2. ポート5000、5001が使用されていないか確認
3. ファイアウォールの設定を確認

### CSVファイルが読み込めない場合
1. ファイルが正しい場所にあるか確認
2. ファイルの文字エンコーディングを確認
3. ファイルの権限設定を確認

### エラーが発生した場合
1. `app.log`ファイルでエラーの詳細を確認
2. `log/recommendation_log.jsonl`で推奨履歴を確認
3. デバッグアプリ（`http://localhost:5001`）で状態確認
4. エラーメッセージが永続表示される場合は手動で閉じる

### 502 Bad Gatewayエラーが発生した場合
1. サーバーのメモリ使用量を確認
2. ワーカープロセスの状態を確認
3. タイムアウト設定を確認（現在300秒に設定）
4. ログでワーカーの再起動状況を確認

### セッション管理エラーが発生した場合
1. ブラウザのCookieをクリア
2. ページを再読み込み
3. 新しいセッションで再試行
4. セッション管理の自動復旧機能により自動的に復旧される場合がある

### 使用上の注意が表示されない場合
1. ChatGPT APIキーが正しく設定されているか確認
2. ネットワーク接続を確認
3. ブラウザのコンソールでエラーメッセージを確認
4. 使用上の注意はChatGPTで自動生成されるため、API制限に注意

### スマホでの表示が崩れる場合
1. ブラウザのキャッシュをクリア
2. ページを再読み込み
3. iPhone Safariの場合は「デスクトップ版Webサイトを表示」をオフに設定

### 質問応答が動作しない場合
1. 質問キーワード（「ですか」「でしょうか」「ドーピング」など）が含まれているか確認
2. セッションが正常に保存されているか確認
3. 管理画面でAI応答の表示を確認
