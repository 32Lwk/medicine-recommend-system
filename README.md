# 医薬品相談AI - 統合ドキュメント

## 📋 概要

このシステムは、症状を入力すると適切な市販薬を提案し、薬の飲み合わせや注意点についてアドバイスを提供するAIシステムです。ルールベースとAIを組み合わせたハイブリッド推奨システムを採用し、安全性と監視機能を大幅に強化した最新版です。

## セットアップ

### 1. 必要なライブラリのインストール

```bash
pip install pandas openai python-dotenv flask
```

### 2. OpenAI APIキーの設定

#### 方法1: 環境変数を使用（推奨）

**Windows PowerShellの場合：**
```powershell
# 一時的な設定（現在のセッションのみ）
$env:OPENAI_API_KEY="your-api-key-here"

# 永続的な設定（ユーザー環境変数）
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "your-api-key-here", "User")
```

**Windows コマンドプロンプトの場合：**
```cmd
# 一時的な設定
set OPENAI_API_KEY=your-api-key-here

# 永続的な設定
setx OPENAI_API_KEY "your-api-key-here"
```

**Linux/Macの場合：**
```bash
# 一時的な設定
export OPENAI_API_KEY="your-api-key-here"

# 永続的な設定（~/.bashrcまたは~/.zshrcに追加）
echo 'export OPENAI_API_KEY="your-api-key-here"' >> ~/.bashrc
source ~/.bashrc
```

#### 方法2: .envファイルを使用

1. 同じディレクトリに`.env`ファイルを作成：
```env
OPENAI_API_KEY=your-api-key-here
```

2. `.gitignore`ファイルに以下を追加：
```
.env
*.env
```

## 使用方法

### Webアプリケーション（メイン）

1. アプリケーションを起動：
```bash
python app.py
```

2. ブラウザで `http://localhost:5000` にアクセス

3. ユーザー名を入力してチャット開始

4. 症状を入力すると、以下の流れで応答：
   - 症状に基づく医薬品推奨（上位3件）
   - 各医薬品の詳細情報（成分・効能・年齢制限）
   - 使用上の注意事項
   - 不足情報がある場合は追加質問

5. 質問応答機能：
   - 「ドーピングに当たりますか？」などの直接的な質問にAIが回答
   - 医薬品の安全性に関する専門的な質問に対応
   - チャット履歴に質問と回答が適切に保存・表示

6. 追加の質問や情報提供が可能

### 管理者チャット機能（監視機能強化）

#### 方法1: 統合版アプリケーション内
1. ブラウザで `http://localhost:5000/admin` にアクセス

2. 全ユーザーのセッションを確認

3. **監視ダッシュボード**: 「監視ダッシュボード」ボタンをクリック
   - アクセス統計（ブラウザ・OS・デバイス分布）
   - パフォーマンス統計（メモリ・CPU・レスポンス時間）
   - リアルタイム監視（エラー率・キャッシュヒット率）
   - データエクスポート機能

4. AI自動応答のオン/オフ切り替え

5. 必要に応じて手動でユーザーに返信

#### 方法2: 独立版管理者アプリケーション
1. 管理者アプリケーションを起動：
```bash
python admin_app.py
```

## 主要機能

### 1. ハイブリッド推奨システム
- 全医薬品種類にルールベース推奨システムを適用
- ChatGPT推奨はフォールバック機能として使用
- 使用上の注意の自動生成（ChatGPT）
- セッション管理の自動復旧機能
- API障害時の自動フォールバック

### 2. ルールベースアルゴリズム
- 症状辞書による高精度マッチング
- 6要素スコアリング（症状適合度、効能特異性、年齢適合性、用法簡便性、副作用リスク、相互作用リスク）
- 成分情報を含む推奨理由の生成
- CSV全列（効能、用法、年齢制限、成分、ドーピング情報など）を活用
- スコア内訳の詳細表示

### 3. 安全性チェック（大幅強化）
- **年齢制限の厳格チェック**: 乳児・幼児・小児・高齢者の詳細分類
- **妊娠・授乳中の禁忌薬除外**: 全医薬品種類での医師受診必須
- **Red Flag症状の検出**: 高熱、激しい痛み、呼吸困難など
- **症状期間による医師相談推奨**: 1週間以上の症状
- **アレルギー成分照合**: 成分名正規化辞書による高精度照合
- **相互作用チェック**: リスクレベル別の詳細警告

### 4. セッション管理
- ユーザー属性の自動抽出と保存
- 会話履歴の保持
- 複数ユーザーの同時対応
- セッションタイムアウト処理
- **セッション管理の自動復旧機能**: セッション消失時の自動復旧
- **セッション初期化の改善**: 新規セッションの自動作成
- **ワーカータイムアウト対策**: Gunicorn設定の最適化とメモリ管理の改善

### 5. 不足情報チェックと質問
- **Critical質問**: 年齢（医薬品選択に必須）
- **Important質問**: 性別、妊娠・授乳状態
- **Optional質問**: 症状期間、服用中の薬、アレルギー
- 優先度に応じた段階的な質問
- 一度回答された質問は繰り返さない

### 6. 詳細な医薬品情報提供（強化版）
- 効能効果のAI要約
- 用法用量からの注意事項抽出
- 個別の年齢制限表示
- 成分情報の推奨理由への組み込み
- ドーピング情報の活用
- **スコア内訳の詳細表示**: 症状適合度、効能特異性、副作用リスク等
- **アレルギー警告**: 成分名正規化による高精度アレルギー検出
- **相互作用警告**: リスクレベル別の詳細警告表示
- **AI生成使用上の注意**: ChatGPTによる個別化された詳細な使用上の注意
- **年齢制限・ドーピング情報の統合**: CSVデータの全列情報を活用した包括的な注意事項
- **エラーメッセージの永続表示**: 自動削除防止と手動閉じる機能

### 7. フィードバックシステム（新規追加）
- **ユーザー評価機能**: 症状分析・医薬品相談回答・重要な注意事項への評価ボタン
- **不具合報告機能**: エラー・警告メッセージからの不具合報告
- **PostgreSQLデータベース**: 永続的なフィードバック保存
- **管理画面統計**: 適切率・不適切率・解決状況の詳細表示
- **Google Form連携**: 詳細な不具合報告の外部フォーム連携
- **評価ボタンの確実な表示**: すべてのAI応答に評価機能を統合

## システムアーキテクチャ

### 推奨フロー

```
ユーザー入力 → 症状分析（NLU）
                ↓
        ┌──────────┴──────────┐
        ↓                     ↓
   ルールベース推奨        ChatGPT推奨
   (全医薬品種類対応)      (フォールバック)
        ↓                     ↓
        └──────────┬──────────┘
                   ↓
         安全性チェック（年齢・妊娠・重症度）
                   ↓
         使用上の注意自動生成（ChatGPT）
                   ↓
         セッション更新 + 推奨結果
```

### ルールベーススコアリング

```
合計スコア = 
  症状適合度 (0-1.0)
  + 効能特異性 (0-1.0)
  + 年齢適合性 (0-1.0)
  + 用法簡便性 (0-1.0)
  - 副作用リスク (0-1.0)
  - 相互作用リスク (0-1.0)
```

#### スコア要素の詳細
- **症状適合度**: ユーザーの症状と医薬品の効能の適合度
- **効能特異性**: 医薬品の効能が症状に対してどれだけ特異的か
- **年齢適合性**: ユーザーの年齢と医薬品の年齢制限の適合度
- **用法簡便性**: 医薬品の用法・用量の簡便性
- **副作用リスク**: 医薬品の副作用のリスクレベル
- **相互作用リスク**: 他の薬との相互作用のリスクレベル

## トラブルシューティング

### APIキーが認識されない場合
1. 環境変数が正しく設定されているか確認
2. `.env`ファイルが正しい場所にあるか確認
3. ファイルの文字エンコーディングがUTF-8か確認
4. プログラムを再起動して環境変数を再読み込み

### Webアプリケーションが起動しない場合
1. Flaskがインストールされているか確認
2. ポート5000、5001が使用されていないか確認
3. ファイアウォールの設定を確認

### CSVファイルが読み込めない場合
1. ファイルが正しい場所にあるか確認
2. ファイルの文字エンコーディングを確認
3. ファイルの権限設定を確認

### エラーが発生した場合
1. `app.log`ファイルでエラーの詳細を確認
2. `log/recommendation_log.jsonl`で推奨履歴を確認
3. デバッグアプリ（`http://localhost:5001`）で状態確認
4. エラーメッセージが永続表示される場合は手動で閉じる

### 502 Bad Gatewayエラーが発生した場合
1. サーバーのメモリ使用量を確認
2. ワーカープロセスの状態を確認
3. タイムアウト設定を確認（現在300秒に設定）
4. ログでワーカーの再起動状況を確認

### セッション管理エラーが発生した場合
1. ブラウザのCookieをクリア
2. ページを再読み込み
3. 新しいセッションで再試行
4. セッション管理の自動復旧機能により自動的に復旧される場合がある

### 使用上の注意が表示されない場合
1. ChatGPT APIキーが正しく設定されているか確認
2. ネットワーク接続を確認
3. ブラウザのコンソールでエラーメッセージを確認
4. 使用上の注意はChatGPTで自動生成されるため、API制限に注意

### スマホでの表示が崩れる場合
1. ブラウザのキャッシュをクリア
2. ページを再読み込み
3. iPhone Safariの場合は「デスクトップ版Webサイトを表示」をオフに設定

### 質問応答が動作しない場合
1. 質問キーワード（「ですか」「でしょうか」「ドーピング」など）が含まれているか確認
2. セッションが正常に保存されているか確認
3. 管理画面でAI応答の表示を確認
