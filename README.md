# 医薬品相談AIプログラム

このプログラムは、症状を入力すると適切な市販薬を提案し、薬の飲み合わせや注意点についてアドバイスを提供するAIシステムです。ルールベースとAIを組み合わせたハイブリッド推奨システムを採用しています。

## 🚀 最新機能（2025年9月）

### ✨ ハイブリッド推奨システム
- **ルールベース推奨**: 風邪薬・解熱鎮痛薬・鼻炎用薬に対して透明性の高いルールベースアルゴリズムを適用
- **AI推奨**: その他の医薬品にはChatGPTによる柔軟な推奨
- **自動判定**: 症状から最適な推奨方式を自動選択

### 🔍 安全性機能
- **Red Flag症状検出**: 重篤な症状を即座に検出し医師相談を推奨
- **年齢制限チェック**: 7歳未満は医師相談、年齢別の適切な医薬品を推奨
- **妊娠・授乳中チェック**: 禁忌薬を自動除外
- **症状期間チェック**: 7日以上継続する症状は医師相談を推奨

### 💬 インテリジェント質問機能
- **不足情報の自動検出**: 年齢・性別・妊娠状態などの重要情報が不足している場合に質問
- **優先度別質問**: Critical → Important → Optional の順で段階的に質問
- **セッション管理**: ユーザーの回答を記憶し、重複質問を回避
- **推奨先行表示**: まず推奨を表示し、その後で追加情報を質問

### 🎯 詳細な医薬品情報
- **成分情報**: 各医薬品の有効成分を表示
- **効能効果**: AIによる要約で分かりやすく説明
- **年齢制限**: 個別の医薬品ごとに年齢制限を明示
- **使用上の注意**: データベース情報を活用した詳細な注意事項

### 👨‍⚕️ 管理者機能
- **手動介入モード**: AIの自動応答を停止し、管理者が手動で返信
- **セッション管理**: 複数ユーザーのセッションを一元管理
- **ログ監視**: 推奨履歴とユーザーの活動をリアルタイムで監視

## セットアップ

### 1. 必要なライブラリのインストール

```bash
pip install pandas openai python-dotenv flask
```

### 2. OpenAI APIキーの設定

#### 方法1: 環境変数を使用（推奨）

**Windows PowerShellの場合：**
```powershell
# 一時的な設定（現在のセッションのみ）
$env:OPENAI_API_KEY="your-api-key-here"

# 永続的な設定（ユーザー環境変数）
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "your-api-key-here", "User")
```

**Windows コマンドプロンプトの場合：**
```cmd
# 一時的な設定
set OPENAI_API_KEY=your-api-key-here

# 永続的な設定
setx OPENAI_API_KEY "your-api-key-here"
```

**Linux/Macの場合：**
```bash
# 一時的な設定
export OPENAI_API_KEY="your-api-key-here"

# 永続的な設定（~/.bashrcまたは~/.zshrcに追加）
echo 'export OPENAI_API_KEY="your-api-key-here"' >> ~/.bashrc
source ~/.bashrc
```

#### 方法2: .envファイルを使用

1. 同じディレクトリに`.env`ファイルを作成：
```env
OPENAI_API_KEY=your-api-key-here
```

2. `.gitignore`ファイルに以下を追加：
```
.env
*.env
```

### 3. データファイルの確認

- `otc_medicine_data.csv`: 市販薬のデータベース
- `summarized_efficacy_data.csv`: 効能要約データ

これらのファイルが同じディレクトリに配置されていることを確認してください。

## 使用方法

### Webアプリケーション（メイン）

1. アプリケーションを起動：
```bash
python app.py
```

2. ブラウザで `http://localhost:5000` にアクセス

3. ユーザー名を入力してチャット開始

4. 症状を入力すると、以下の流れで応答：
   - 症状に基づく医薬品推奨（上位3件）
   - 各医薬品の詳細情報（成分・効能・年齢制限）
   - 使用上の注意事項
   - 不足情報がある場合は追加質問

5. 追加の質問や情報提供が可能

### 管理者チャット機能

1. ブラウザで `http://localhost:5000/admin` にアクセス

2. 全ユーザーのセッションを確認

3. AI自動応答のオン/オフ切り替え

4. 必要に応じて手動でユーザーに返信

### デバッグアプリケーション

1. デバッグ用アプリケーションを起動：
```bash
python debug_app.py
```

2. ブラウザで `http://localhost:5001` にアクセス

3. システム状態、ログ、パフォーマンス統計を確認

## 主要機能

### 1. ハイブリッド推奨システム
- ChatGPTで医薬品種類を自動判定
- 風邪薬・解熱鎮痛薬・鼻炎用薬 → ルールベース推奨
- その他の医薬品 → AI推奨
- API障害時の自動フォールバック

### 2. ルールベースアルゴリズム
- 症状辞書による高精度マッチング
- 多因子スコアリング（症状マッチ度、効能効果、年齢適合性）
- 成分情報を含む推奨理由の生成
- CSV全列（効能、用法、年齢制限、成分など）を活用

### 3. 安全性チェック
- Red Flag症状の検出（高熱、激しい痛み、呼吸困難など）
- 年齢制限の厳格チェック
- 妊娠・授乳中の禁忌薬除外
- 症状期間による医師相談推奨

### 4. セッション管理
- ユーザー属性の自動抽出と保存
- 会話履歴の保持
- 複数ユーザーの同時対応
- セッションタイムアウト処理

### 5. 不足情報チェックと質問
- **Critical質問**: 年齢（医薬品選択に必須）
- **Important質問**: 性別、妊娠・授乳状態
- **Optional質問**: 症状期間、服用中の薬、アレルギー
- 優先度に応じた段階的な質問
- 一度回答された質問は繰り返さない

### 6. 詳細な医薬品情報提供
- 効能効果のAI要約
- 用法用量からの注意事項抽出
- 個別の年齢制限表示
- 成分情報の推奨理由への組み込み
- ドーピング情報の活用

## セキュリティと安全性

### APIキーの安全な管理

1. **絶対にGitにコミットしない**
   - APIキーを含むファイルは`.gitignore`に追加
   - 公開リポジトリにAPIキーをアップロードしない

2. **環境変数の使用を推奨**
   - システム環境変数として設定
   - アプリケーション固有の設定として管理

3. **.envファイルの使用**
   - ローカル開発環境での使用
   - 本番環境では環境変数を使用

4. **定期的なキーのローテーション**
   - 定期的にAPIキーを更新
   - 不要になったキーは削除

### 医薬品推奨の安全性

- このプログラムは医療アドバイスではありません
- 最終的な判断は医師や薬剤師に相談してください
- 体調に変化があった場合は専門家にご相談ください
- Red Flag症状検出時は即座に医師相談を推奨

```
        ↓                     ↓

        ↓                     ↓
        └──────────┬──────────┘

                   ↓
```


## トラブルシューティング

### APIキーが認識されない場合
1. 環境変数が正しく設定されているか確認
2. `.env`ファイルが正しい場所にあるか確認
3. ファイルの文字エンコーディングがUTF-8か確認
4. プログラムを再起動して環境変数を再読み込み

### Webアプリケーションが起動しない場合
1. Flaskがインストールされているか確認
2. ポート5000、5001が使用されていないか確認
3. ファイアウォールの設定を確認

### CSVファイルが読み込めない場合
1. ファイルが正しい場所にあるか確認
2. ファイルの文字エンコーディングを確認
3. ファイルの権限設定を確認

### エラーが発生した場合
1. `app.log`ファイルでエラーの詳細を確認
2. `log/recommendation_log.jsonl`で推奨履歴を確認
3. デバッグアプリ（`http://localhost:5001`）で状態確認
