# 診断名検出後の Physical / OTC 可否マトリクス（ターゲット）

**原則**: 診断検出後も **パターンに応じて** 質疑応答・医薬品推奨を行う（一律ブロックしない）。ただし **serious** と **Emergency** は例外。

**セッションフラグ**（将来実装）:

- `diagnosis_blocks_otc` — 診断ガードが有効なセッション
- `diagnosis_block_types[]` — 検出された type を **すべて** 記録（例: `['chronic','mental_health']`）
- **新規セッション**でクリア。「もう薬はいい」では解除しない
- フラグが立っていても、下表の **許可パターン**では Physical / OTC 可

**優先順位**: **Emergency / 赤旗 > 診断ガード**（診断があっても Emergency 経路を優先）

**情報提供**: 医薬品以外（受診先・生活習慣・セルフケア一般論）は可。**PMDA / 添付文書 / 学会ガイドに根拠のない記述は出さない**（誤情報厳禁）。

---

## type 別デフォルト

| type | デフォルト | 備考 |
|------|------------|------|
| **serious** | OTC **完全ブロック**（セッション継続） | 癌+市販薬探索含む |
| **chronic** | カウンセリング優先。**症状特異的 OTC は条件付き可** | 高血圧+頭痛は可（下表） |
| **mental_health** | カウンセリング優先。**原則 OTC 慎重** | **不眠症**はカウンセリング後 OTC 可 |
| **other** | カウンセリング優先 | てんかん+発作中 → 赤旗 **かつ** OTC ブロック |

## パターンマトリクス

| パターン | serious | chronic | mental_health | other |
|----------|---------|---------|---------------|-------|
| **診断名のみ** | 通知のみ・OTC なし | 同左 | 同左 | 同左 |
| **診断 + 症状**（探索なし） | 通知 → カウンセリング → **OTC 不可** | カウンセリング優先 → **type・症状により OTC 可** | 同左（**不眠症**は後述） | カウンセリング優先；**発作中**は赤旗+OTC不可 |
| **診断 + OTC 探索**（市販薬/何の薬） | **OTC 不可** | **パターン判定**（糖尿病等は原則不可、高血圧+頭痛は可） | **パターン判定**（うつ+不眠は原則不可、不眠症診断はカウンセリング後可） | **原則 OTC 不可**（てんかん発作中は不可） |
| **診断 + 治療中**（通院・処方薬） | OTC 不可 | **カウンセリングのみ**（OTC 原則なし） | 同左（**不眠症**は例外） | 同左 |
| **診断 + 副作用言及** | **OTC 不可**（early return 維持） | 同左 | 同左 | 同左 |
| **高リスクコンテキスト**（検査中・疑い等） | OTC 不可 | OTC 不可 | OTC 不可 | OTC 不可 |
| **Triage が Physical でも** | **ブロック** | **パターンで許可** | **パターンで許可** | **発作中はブロック** |
| **過去形・完治**（検出除外） | — | 通常症状フロー | 通常症状フロー | 通常症状フロー |

## 過去形（Q2 推奨 — コード既存ロジックと整合）

`diagnosis_detection.py` は診断名近傍の **過去・完治・他人** 表現で検出を **スキップ** する。

| 文言例 | 推奨 |
|--------|------|
| `うつ病でしたが完治しました` / `昔うつ病` | 診断ブロック **なし** → 通常症状フロー |
| `うつ病でした` のみ（現病不明） | **カウンセリング1ターン**（通院・服薬の有無を確認）。確定まで hard block しない |
| `うつ病でしたが今は治療中` / `通院中` | **active** → mental_health 扱い・治療中パターン |
| `治療中` + 診断名 | **カウンセリングのみ**（Q3: はい） |

実装 PR では除外キーワードを `tests/test_diagnosis_detection.py` で固定する。
