# 診断名検出後の Physical / OTC 可否マトリクス（ターゲット）

**原則**: 診断検出後も **パターンに応じて** 質疑応答・医薬品推奨を行う。ただし **serious**・**Emergency**・**副作用**・**高リスク chronic** は例外。

**セッションフラグ**（実装 PR）:

- **`diagnosis_session_active`** — 診断が検出されたセッション（旧案 `diagnosis_blocks_otc` は使用しない）
- **`diagnosis_block_types[]`** — 検出 type を **すべて** 記録
- **新規セッション**でクリア。「もう薬はいい」では解除しない
- フラグが立っていても **許可パターン**では Physical / OTC 可

**複数診断**: type が複数あるときは **より厳しい方**（OTC 不可側）を適用。

**優先順位**: **Emergency / 赤旗 > 診断ガード**

**情報提供**: 医薬品以外は可。**PMDA / 添付文書 / 学会に根拠のない断定禁止**。カウンセリング文は **かかりつけ医・薬剤師への相談**を必須（Q13）。

**カウンセリング → Physical**: オーケストレーター判断。推奨質問・ゲートは [diagnosis-counseling-orchestrator.md](diagnosis-counseling-orchestrator.md)。

---

## type 別デフォルト

| type | デフォルト | 備考 |
|------|------------|------|
| **serious** | OTC **完全ブロック** | 癌+頭痛（探索なし）も不可 |
| **chronic** | カウンセリング優先 | **高血圧+頭痛のみ** OTC 可。糖尿病・CKD・心不全等は不可 |
| **mental_health** | カウンセリング優先 | **不眠症（成人）**はカウンセリング後 OTC 可。うつ+睡眠薬探索は不可 |
| **other** | カウンセリング優先 | IBD+腹痛は OTC 不可。てんかん+発作は赤旗+不可 |

---

## chronic 頭痛・腹痛 — リスク別

| 既往 | 症状 | OTC |
|------|------|-----|
| 高血圧 | 頭痛 | **可**（GC-SAFE-DX-006） |
| 糖尿病 | 頭痛 | **不可**（GC-SAFE-DX-004） |
| 慢性腎臓病・心不全 等 | 頭痛 | **不可**（GC-SAFE-DX-008） |
| IBD・潰瘍性大腸炎等 | 腹痛 | **不可**（GC-SAFE-DX-009） |

---

## 不眠・睡眠

| 入力 | フロー | OTC |
|------|--------|-----|
| **不眠症**（診断名）+ 探索、**成人** | カウンセリング → Physical | **可**（GC-SAFE-DX-005b） |
| **不眠症** + **小児** | カウンセリング | **不可**（Q14） |
| **眠れない**（診断名なし） | **カウンセリング → Physical**（通常直行しない） | ゲート充足後 **可**（GC-SAFE-DX-010） |
| **うつ病** + 不眠 | カウンセリング | **不可**（GC-SAFE-DX-005） |
| **うつ病** + 「市販の睡眠薬を教えて」 | カウンセリング・受診案内 | **不可**（GC-SAFE-DX-005c） |

## パターンマトリクス（要約）

| パターン | serious | chronic | mental_health | other |
|----------|---------|---------|---------------|-------|
| 診断名のみ | OTC なし | OTC なし | OTC なし | OTC なし |
| 診断+症状 | OTC 不可 | 上表参照 | 上表参照 | 上表参照 |
| 診断+OTC探索 | OTC 不可 | 上表参照 | 上表参照 | 原則不可 |
| 診断+治療中 | OTC 不可 | OTC 不可 | OTC 不可（不眠症成人も治療中は不可） | OTC 不可 |
| 副作用言及 | OTC 不可 | 同左 | 同左 | 同左 |
| 過去形・完治（除外） | — | 通常フロー※ | 同左 | 同左 |

※「眠れない」は診断除外後も **カウンセリング経由**（Q4）。
