# Golden cases: 月経・女性特有

出典: `test_menstrual_recommendations.py`

---

### GC-MEN-001: 生理不順+イライラ（基本）

- **ペルソナ**: PERS-A02
- **入力**: `生理不順で、なおかつイライラする`
- **期待**: top3≥2件。期待漢方・ラムール系が top10 内
- **根拠**: `test_basic_menstrual_irregularity`

### GC-MEN-002: 随伴症状「あれこれ」

- **ペルソナ**: PERS-A02
- **入力**: `生理不順で、なおかつイライラする。あれこれ気になる症状があります`
- **期待**: 命の母ホワイト / 桂枝茯苓丸 等
- **根拠**: `test_accompanying_symptoms_preference`

### GC-MEN-003: 生理痛単独

- **ペルソナ**: PERS-A02
- **入力**: `生理痛がひどいです`
- **期待**: 解熱鎮痛 or 月経痛向け漢方（MENSTRUAL_MEDICINE_PRIORITY）
- **根拠**: integration 詳細

### GC-MEN-004: 生理痛+頭痛複合

- **ペルソナ**: PERS-A02
- **入力**: `生理痛がひどくて、下腹部が痛いです。頭痛もあります`
- **期待**: 月経+鎮痛。成分重複注意
- **根拠**: integration 詳細

### GC-MEN-005: 妊娠可能性+活血禁忌

- **ペルソナ**: PERS-Poss
- **入力**: `生理不順で、なおかつイライラする。妊娠の可能性があります`
- **期待**: 桃仁・牡丹皮含有なし
- **根拠**: `test_pregnancy_contraindication`

### GC-MEN-006: 生理痛悪化エスカレーション

- **ペルソナ**: PERS-A02
- **入力**: `生理痛が年々ひどくなっている`
- **期待**: 受診勧奨メッセージ
- **根拠**: `test_severity_escalation`

### GC-MEN-007: 複合症状（不順+イライラ+ニキビ+冷え）

- **ペルソナ**: PERS-A02
- **入力**: `生理不順で、なおかつイライラして、ニキビもできて、冷え症で、頭痛もします`
- **期待**: 複合向け漢方候補。top3 多様性
- **根拠**: `test_complex_symptoms`

### GC-MEN-008: つわり（妊娠）

- **ペルソナ**: PERS-P35
- **入力**: `妊娠中です。つわりで吐き気があります`
- **期待**: 受診・妊娠中注意。安易な OTC 止吐のみは慎重
- **根拠**: integration ユーザー情報; PREGNANCY_SYMPTOMS

### GC-MEN-009: バランス+随伴（複合嗜好）

- **ペルソナ**: PERS-BAL + PERS-A02
- **入力**: `生理不順で、なおかつイライラする。バランス重視で、あれこれ気になる症状があります`
- **期待**: GC-MEN-001 + GC-MEN-002 の合成
- **根拠**: `test_user_preference_combinations`

### GC-MEN-010: 生理不順のみ（境界スコア）

- **ペルソナ**: PERS-A02
- **入力**: `生理不順`
- **期待**: 推奨≥2。スコア閾値 0.35 以上（テスト基準）
- **根拠**: `test_scoring_boundary_values`
