# Golden cases: 風邪以外の領域

---

## 解熱鎮痛・頭痛

### GC-DOM-HEAD-001: 緊張性頭痛

- **ペルソナ**: PERS-A01
- **入力**: `頭痛がします。ズキズキと痛みます`
- **期待**: 解熱鎮痛薬
- **根拠**: integration 基本症状

### GC-DOM-HEAD-002: 激しい頭痛（赤旗寄り）

- **ペルソナ**: PERS-A02
- **入力**: `激しい頭痛です。今まで経験したことのない頭痛です`
- **期待**: 受診優先（RED_FLAG 激しい頭痛）
- **避ける**: OTC のみで完結
- **根拠**: `RED_FLAG_SYMPTOMS`
