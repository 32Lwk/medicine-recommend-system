# 診断・不眠 — カウンセリング → Physical のオーケストレーター基準

**方針**: 何ターンで Physical に進むかは **オーケストレーター（Concierge / カウンセリングエージェント）が判断**する。本ドキュメントは **推奨の最低確認項目** と **Physical 遷移のゲート**。

**全カウンセリング文面**: 末尾に **「かかりつけ医・薬剤師にご相談ください」** を含める（オーナー Q13）。効能・禁忌の断定は **PMDA / 添付文書** に限定。

---

## Physical 遷移の共通ゲート（オーケストレーター）

以下がすべて満たされたら `run_recommendation_flow` / Physical へ遷移してよい（不足時は質問継続）:

| # | 項目 | 必須理由 |
|---|------|----------|
| 1 | **年齢**（または年齢帯） | 小児厳格・禁忌 |
| 2 | **妊娠・授乳**（該当時） | 禁忌製品除外 |
| 3 | **主症状**が確定（例: 不眠・頭痛） | NLU スコープ |
| 4 | **赤旗・Emergency なし** | 安全ゲート優先 |
| 5 | **診断ガード**のマトリクスで当該ターンが OTC 可 | [diagnosis-physical-block-matrix.md](diagnosis-physical-block-matrix.md) |
| 6 | **併用薬・治療中**（診断・慢性・精神系では特に） | 相互作用 |
| 7 | **診断セッション**で複数 type 時は **より厳しい type** を適用 | オーナー Q8 |

オーケストレーターは上記を満たすまで **製品名の top3 を出さない**。

## 不眠・睡眠 — 推奨質問セット（オーケストレーター向け）

診断名「不眠症」でも症状「眠れない」でも、**最初はカウンセリングフロー**（通常フロー直行しない）。

| 優先 | 質問テーマ | 例 |
|------|------------|-----|
| P0 | 年齢・妊娠授乳 | 「年齢を教えてください」 |
| P0 | 小児判定 | 15歳未満等 → **不眠の OTC 推奨不可**（Q14） |
| P1 | 期間・パターン | 「いつから」「寝付き／中途／早朝」 |
| P1 | うつ・不安の併存 | 「気分の落ち込み・不安はありますか」 |
| P1 | 処方薬・通院 | 「現在のお薬・通院先」 |
| P2 | カフェイン・酒・夜勤 | 生活要因 |
| P2 | 他症状（呼吸困難・激しい頭痛等） | 赤旗除外 |
| P2 | 市販薬の使用歴 | 重複・依存リスク |

**不眠症診断 + 成人**: P0〜P1 を満たし、うつ病併記・治療中でなければ Physical 可（GC-SAFE-DX-005b）。

**「眠れない」のみ**: 診断名は立てないが **同じカウンセリング経路** → 条件充足後 Physical（GC-SAFE-DX-010）。

**うつ病 + 市販睡眠薬の明示質問**: カウンセリング継続、**睡眠薬 OTC top3 不可**（GC-SAFE-DX-005c）。

## chronic 頭痛 — OTC 可/不可の判定（オーケストレーター前）

| 既往 | 頭痛 OTC |
|------|----------|
| **高血圧** | **可**（警告必須）— GC-SAFE-DX-006 |
| **糖尿病** | **不可** — GC-SAFE-DX-004 |
| **慢性腎臓病・心不全** 等 | **不可**（リスク高）— GC-SAFE-DX-008 |
| 複数 chronic | **不可側**を採用 |

## セッションフラグ（実装 PR）

| 旧名（ドキュメント暫定） | 新名 |
|--------------------------|------|
| `diagnosis_blocks_otc` | **`diagnosis_session_active`** |

`diagnosis_session_active == true` は「診断が一度検出されたセッション」であり、**常に OTC 禁止ではない**（パターンで Physical 可）。

`diagnosis_block_types[]` は複数 type を保持。
