# 診断・不眠 — カウンセリング → Physical のオーケストレーター基準

**方針**: Physical 遷移は **オーケストレーターが判断**。本ドキュメントは **最低確認項目** と **ゲート**。

**カウンセリング文面**: 末尾に **「かかりつけ医・薬剤師にご相談ください」**（**日本語固定** — i18n は別 PR）。効能・禁忌は **PMDA / 添付文書** のみ。

---

## Physical 遷移の共通ゲート

| # | 項目 |
|---|------|
| 1 | 年齢（小児不眠 → OTC 不可） |
| 2 | 妊娠・授乳（該当時）— **高血圧+頭痛でも妊娠なら OTC 不可** |
| 3 | 主症状確定 |
| 4 | 赤旗・Emergency なし |
| 5 | [マトリクス](diagnosis-physical-block-matrix.md) で OTC 可 |
| 6 | **治療中でない**（不眠症は処方睡眠薬等があると OTC 不可） |
| 7 | 複数診断 → **より厳しい type** |

## 不眠・睡眠

| 優先 | 質問テーマ |
|------|------------|
| P0 | 年齢・妊娠授乳 |
| P1 | 期間・入眠/中途/早朝 |
| P1 | **うつ・不安の併存**（「ありません」の明示確認） |
| P1 | 処方薬・通院（**治療中なら OTC 不可**） |
| P2 | 生活要因・市販薬使用歴 |

| ケース | ターゲット |
|--------|------------|
| 不眠症・成人・非治療中 | ゲート後 OTC 可（GC-SAFE-DX-005b） |
| 不眠症・**治療中** | OTC **不可** |
| 不眠症・小児 | OTC **不可** |
| **眠れない**のみ | カウンセリング経由；**うつ否認を確認後**ゲート充足で Physical 可（GC-SAFE-DX-010）— 追加ルール実装は不要 |
| うつ病+市販睡眠薬質問 | OTC **不可**（GC-SAFE-DX-005c） |

---

## chronic 頭痛 — 拒否リスト / 許可

**許可**: 高血圧 + 頭痛（**非妊娠**）— GC-SAFE-DX-006

**拒否**（頭痛 OTC 不可）: 糖尿病、慢性腎臓病、**心不全**（GC-SAFE-DX-008b）、**肝硬変**、**透析中**、妊娠中の高血圧（GC-SAFE-DX-006b）、その他高リスク chronic
