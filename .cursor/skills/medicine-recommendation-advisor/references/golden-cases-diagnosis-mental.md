# Golden cases: mental_health 診断名（`diagnosis_detection.py` 準拠）

`diagnosis_type == 'mental_health'` は **カウンセリング優先・パターンで OTC 可否が変わる**（[マトリクス](diagnosis-physical-block-matrix.md)）。**例外: 不眠症診断**はカウンセリング後 OTC 可。

各グループ代表 1 件。キーワードは `src/core/diagnosis_detection.py` の `mental_health_diagnoses` と同期すること。

---

### GC-DX-MH-001: うつ病 + 症状

- **入力**: `うつ病ですが、不眠が続いています`
- **ターゲット**: カウンセリング優先。OTC **原則なし**（GC-SAFE-DX-005）
- **現状**: OTC あり得る
- **キーワード**: うつ病, 鬱病, 憂鬱症, 抑うつ

### GC-DX-MH-002: 双極性障害

- **入力**: `双極性障害の治療中ですが、頭痛があります`
- **ターゲット**: OTC なし
- **キーワード**: 双極性障害, 躁うつ

### GC-DX-MH-003: 不安障害

- **入力**: `不安障害で、動悸と不眠があります`
- **ターゲット**: OTC なし
- **キーワード**: 不安障害, パニック障害

### GC-DX-MH-004: PTSD

- **入力**: `PTSDですが、眠れません`
- **ターゲット**: OTC なし
- **キーワード**: PTSD, 心的外傷後ストレス障害, 適応障害

### GC-DX-MH-005: 摂食障害

- **入力**: `拒食症ですが、めまいがします`
- **ターゲット**: OTC なし
- **キーワード**: 拒食症, 神経性無食欲症, 過食性障害

### GC-DX-MH-006: ADHD / ASD

- **入力**: `ADHDですが、集中できません`
- **ターゲット**: OTC なし（OTC 刺激薬誤推奨に注意）
- **キーワード**: ADHD, 自閉症スペクトラム, ASD

### GC-DX-MH-007: 認知症

- **入力**: `認知症ですが、頭痛がします`
- **ターゲット**: OTC なし
- **キーワード**: 認知症, アルツハイマー, MCI

### GC-DX-MH-008: 統合失調症

- **入力**: `統合失調症ですが、不眠です`
- **ターゲット**: OTC なし
- **キーワード**: 統合失調症, 精神病

### GC-DX-MH-009: 依存症

- **入力**: `アルコール依存症ですが、胃の調子が悪いです`
- **ターゲット**: OTC なし
- **キーワード**: 依存症, アルコール依存症

### GC-DX-MH-010: 不眠症（リスト内・成人）

- **入力**: `不眠症です。市販の睡眠薬を探しています`
- **ターゲット**: **カウンセリング後 → OTC 可**（GC-SAFE-DX-005b）。[オーケストレーター基準](diagnosis-counseling-orchestrator.md)
- **小児**: **OTC 不可**（Q14）
- **キーワード**: 不眠症, 慢性不眠症

### GC-DX-MH-011: 精神疾患（総称）

- **入力**: `精神疾患がありますが、疲れが取れません`
- **ターゲット**: OTC なし
- **キーワード**: 精神疾患, 精神病, 神経症

### GC-DX-MH-012: 境界性パーソナリティ障害

- **入力**: `境界性パーソナリティ障害ですが、イライラします`
- **ターゲット**: OTC なし
- **キーワード**: BPD, パーソナリティ障害

**メンテ**: `mental_health_diagnoses` をコード変更したら本ファイルの代表入力を見直す。
