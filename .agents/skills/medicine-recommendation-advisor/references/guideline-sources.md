## 使い方

1. ユーザーの主症状から上表で学会を 1–2 個選ぶ。
2. WebSearch: `site:jsaweb.jp 花粉症 ガイドライン` 等で **改訂年** を確認。
3. OTC が適切か不明ならガイドライン上の受診・治療ラインを引用し **受診優先** を検討。
4. ガイドラインと PMDA が矛盾する稀なケースは **PMDA（製品ラベル）> 学会 GL（病態治療）** の順で整理し、人間レビューを促す。
