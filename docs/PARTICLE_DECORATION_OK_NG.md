# 季節装飾・パーティクル：文化的配慮（OK / NG 方針）

医薬品相談 UI として、**特定宗教・政治・過度にリアルな医療表現**は避ける。以下はガイドラインであり、コンテンツ追加時にレビューする。

| 区分 | OK（例） | NG（例） |
|------|----------|----------|
| 七夕 | 短冊・星・竹を連想する抽象的・淡色の装飾 | 特定地域の宗教儀礼を想起させる過度な象徴 |
| 敬老の日 | 花・ギフトを連想する穏やかなモチーフ | 高齢者を揶揄・ステレオタイプ化する表現 |
| ハロウィン | かぼちゃ・星・淡色の「軽い」装飾 | 流血・ホラー・子どもが怖がる写実表現 |
| 七五三 | 和の祝い事を連想する穏やかな装飾 | 特定神社・商業キャラの無断類似 |
| バレンタイン / ホワイトデー | ハート・チョコ・手紙のモチーフ | 恋愛成就の断定表現、性的含意の強い表現 |
| 粒子（全般） | 淡色・中間色・絵文字レベルの抽象 | `#000` や極端な暗色で文字をかき消す視認性 |

詳細な色・コントラスト方針は `PARTICLE_COLOR_POLICY.md`、コントラスト数値表は `PARTICLE_CONTRAST_VERIFICATION.md` を参照。
