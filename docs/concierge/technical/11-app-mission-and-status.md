# 作成意図・現状 — medicine-recommend（Concierge SSOT）

> アプリ概要・作成意図の**技術 SSOT 要約**。詳細 FAQ は `docs/concierge/rag/app-overview-rag.md`、公開正本は `docs/public/アプリ概要.md`。

## なぜ作ったか（What / Why）

- **What**: チャット形式で症状に基づき一般用医薬品（市販薬）の候補を提示する β 版ツール
- **Why**: 少子高齢化・訪日外国人増・EC 普及でセルフメディケーション需要は高い一方、薬局現場では人手不足と言語の壁があり、利用者が適切な市販薬を選びにくい
- **きっかけ**: ドラッグストア勤務経験 — 高齢者の理解力の差や外国人との言語障壁を実感
- **Trade-off**: 診断・処方は行わず、**参考情報**に限定。最終判断は薬剤師・医師等の専門家に委ねる

## 何を目指しているか

- 誰もが安心してセルフメディケーションの**参考**にできる環境
- ルールベーススコアリングで市販薬候補を選定し、LLM は説明・会話振り分けに限定（薬名の自由創作はしない）
- 多言語（日本語・英語・中国語・韓国語）とアクセシビリティ（読み上げ・文字サイズ等）への配慮
- 薬局来店前・オンライン購入前の**参考情報**として、受診判断の一助にもなる設計

## 本アプリが**ない**もの（例外・境界）

| 区分 | 内容 |
|------|------|
| **医療機関ではない** | 病院・診療所ではなく、医師による診察・処方は行わない |
| **診断・治療行為なし** | 病名の確定診断、治療方針の決定、処方薬の推奨は行わない |
| **専門家の代替ではない** | 薬剤師・登録販売者・医師の指導を代替するものではない |
| **医療アドバイスではない** | 提供は**情報提供**に限る（免責事項・利用規約に準拠） |
| **商用サービスではない（β）** | 非営利・学術研究目的の試験運用。商用利用はライセンス・規約の範囲外 |
| **一般公開ではない（β）** | 一般消費者向けの正式公開は検討段階。本 β は限定公開の評価・検証 |
| **違法・規制薬物** | 違法薬物・規制薬物に関する相談には対応しない |
| **緊急医療** | 119 や即時受診が必要な場合は EmergencyRouter で受診・通報を案内するが、救急そのものは提供しない |

**ユーザー向け応答の原則**: 「病院ですか？」等の yes/no 確認には医療機関のように「はい」と答えず、チャット型市販薬相談ツールであることを短く説明する（`concierge_knowledge.ja.json` policy_snippet 参照）。

## 対象者

### β版（現状・2026-07 時点）

| 区分 | 対象 |
|------|------|
| **主なテスター** | 薬剤師・登録販売者などの医薬専門職 |
| **関係者** | 医療・行政・研究機関に所属する関係者 |
| **企業** | 医薬品販売やセルフメディケーション支援に関心のある企業担当者 |
| **性質** | 非営利・学術目的の実証研究・フィードバック収集 |

研究の一環として、将来の想定利用者（一般消費者・訪日外国人等）へのユーザーヒアリングにご協力いただく場合がある（**本 β の一般公開を意味するものではない**）。

### 将来の想定利用者（実用化時の例）

- どの薬を選べばよいかわからない一般消費者
- 忙しくて薬局に行けない人、過疎地域の住民
- 言語の壁で相談が難しい訪日外国人
- 高齢者や聴覚・理解力に個人差のある方
- EC・オンライン薬局で購入を検討する利用者

## β版の制限・注意

| 項目 | 内容 |
|------|------|
| **版** | β版（試験運用・限定公開） |
| **目的** | UI/UX と独自選定アルゴリズムの有効性検証、専門家フィードバック収集 |
| **一般公開** | 正式な一般消費者向け公開は**検討段階** |
| **内容の正確性** | 研究段階のため、推奨内容は参考情報。必ず薬剤師・医師等に相談すること |
| **機能の変動** | 検証中のため UI・アルゴリズム・対応範囲が更新される可能性がある |
| **データ** | 入力は匿名化設計だが、試験運用である点を理解した上で利用 |
| **将来研究** | 症状表現の揺れ対応強化（ルールベース + 意味類似のハイブリッド評価）は継続改善中。未実装の研究要素は「検討中」と回答する |

## Q&A RAG（作成意図・現状 — 要約）

### Q: なぜこのアプリを作ったのか

<!-- rag-keywords: なぜ 作った 作成意図 目的 背景 セルフメディケーション 開発 -->

**回答要点**

- セルフメディケーション需要の増加と、薬局現場の人手不足・言語の壁が背景
- チャットで症状を伝え、市販薬候補と受診目安を**参考**として提示するツール
- ドラッグストア現場での課題（高齢者・外国人への説明不足）から着想
- **Trade-off**: 診断・処方は行わず、専門家の判断を補助する情報提供に限定

**例外・境界**: 医療行為・診断の代替ではない。β版は限定公開の検証目的。

### Q: 今 β版なのか。誰向けか

<!-- rag-keywords: β版 ベータ 試験 限定公開 誰向け 対象 テスター -->

**回答要点**

- **What**: 研究開発中の β版（試験運用版）として限定公開
- **Who**: 薬剤師・登録販売者・医療・行政・研究・企業関係者等の専門関係者
- **Why**: 実証研究・検証・フィードバック収集（非営利・学術目的）
- 一般消費者向けの正式公開は検討段階 — 本 β は一般公開ではない

**例外・境界**: 一般公開を意味する表現は使わない。ヒアリング協力 ≠ 一般公開。

### Q: 病院・医療機関ですか

<!-- rag-keywords: 病院 医療機関 診察 診断 クリニック 診療所 -->

**回答要点**

- **No**: 病院・診療所ではない。医師による診察・処方は行わない
- **What**: チャット型の一般用医薬品（市販薬）相談ツール（β版）
- yes/no 確認には「はい（病院です）」と答えず、本ツールの性質を説明する

**例外・境界**: 緊急時は受診・119 案内。それでも医療機関そのものではない。

### Q: 診断や処方はしてくれるか

<!-- rag-keywords: 診断 処方 治療 病名 確定 医師 代替 -->

**回答要点**

- 診断・治療行為・処方薬の推奨は**行わない**
- 市販薬（一般用医薬品）の候補提示と、受診が必要な症状の目安を**参考情報**として提供
- 最終判断は薬剤師・医師・登録販売者等の専門家に相談すること

**例外・境界**: 危険症状では受診勧奨。それは診断ではなく安全上の案内。

### Q: セルフメディケーション支援とは何を指すか

<!-- rag-keywords: セルフメディケーション 自己負担 市販薬 OTC 自己判断 -->

**回答要点**

- 利用者が自身の症状を正しく伝え、市販薬を**安全に選択する一助**となる支援
- 薬局来店前・オンライン購入前の参考情報、受診判断の補助
- ルールベース推奨 + LLM による会話理解のハイブリッド設計

**例外・境界**: セルフメディケーションの「推奨」は情報提供であり、医師・薬剤師の指導に代わるものではない。

### Q: 市販薬の選び方は LLM が決めるのか

<!-- rag-keywords: ルールベース LLM 薬 選定 スコアリング アルゴリズム ハイブリッド -->

**回答要点**

- **薬名の最終選定はルールベース**（症状辞書・効能・年齢・副作用・相互作用等のスコアリング）
- LLM は症状理解（NLU）・説明・会話振り分けに限定 — **薬名を自由創作して決めない**
- ハルシネーション抑制と薬事的妥当性を優先

**例外・境界**: 技術詳細は `12-technical-faq-rag.md` / `PhysicalOrchestrator` 参照。

### Q: 対応言語は

<!-- rag-keywords: 多言語 言語 日本語 英語 中国語 韓国語 翻訳 -->

**回答要点**

- 日本語・英語・中国語・韓国語に対応
- 翻訳 API（DeepL 等）による高速翻訳
- 訪日外国人や言語の壁がある利用者への配慮が開発動機の一つ

**例外・境界**: 翻訳精度により nuance が失われる場合がある。重要な判断は母語で専門家に相談を推奨。

### Q: 将来の展望は

<!-- rag-keywords: 将来 展望 ロードマップ 連携 薬局 自治体 LINE EC -->

**回答要点**

- 薬局・医療機関・自治体連携、地域医療のデジタル支援基盤としての活用検討
- EC・LINE 連携など利用者と販売者双方への価値提供
- 症状表現の揺れへの対応強化（ハイブリッド評価の継続改善）
- 具体的な時期・提携名は公開 doc に無い場合は「検討中」と回答

**例外・境界**: 未実装機能を「既に提供している」と答えない。
