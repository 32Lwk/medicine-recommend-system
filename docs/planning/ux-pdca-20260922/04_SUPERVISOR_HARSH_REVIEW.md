# 04 上司による辛口レビュー（部下レポート殺傷）

**役割**: プロダクト責任者の上司  
**対象**: 市場・チャネル・登録・見た目・待ち・VH・安全維持の主張群

---

## 総評

部下のリサーチは**量はある**。しかし「市場が大きい」「parity を揃えろ」「会員を作れ」「綺麗にしろ」「進捗で誤魔化せ」「アバターで差を出せ」「安全は現状維持でよい」——この 7 つは、どれも**部分的に正しく、戦略としては危険**。以下、殴る。

---

## 主張 1: 「市場拡大だから UX 投資しろ」

**穴**:
- OTC 2025 は広義で**前年割れ**指摘あり。成長ストーリーを前提にすると計画が腐る。
- 本プロダクトは**非営利β・専門家向け**。市場規模は「将来の物語」であって、今四半期の成功指標ではない。
- NotebookLM / Web の数字は定義がバラバラ。単一の「兆円」でスライドを作るな。

**正しい読み**: 規制と信頼が市場のボトルネック。UX 投資の正当化は**安全実証と専門家評価の回転**で語れ。

**判定**: Pivot（市場スライドは背景 1 枚まで）。

---

## 主張 2: 「LINE と Web の parity を揃えろ」

**穴**:
- 薬局 LINE の勝ちパターンは処方箋・待ち時間通知。本 LINE は OTC 相談。用途が違う。
- TTS を LINE に無理移植、Flex を Sage 完全クローン——工数対効果が最悪。
- **揃えるべきは機能一覧ではなく安全契約**（pending cancel、緊急優先、出口 CTA）。

**正しい読み**: Intentional asymmetry（意図的非対称）を文書化し、安全軸だけ対称化。

**判定**: Pivot（parity → safety symmetry）。

---

## 主張 3: 「Web 会員登録を導入しろ」

**穴**:
- 高齢・夜間発熱・匿名相談ニーズと正面衝突。離脱の最短ルート。
- プラポリは氏名・電話を原則収集しない。メール会員は**法務改定が前提**。
- 「ユーザー情報登録」という既存文言が既に誤解を生んでいる。その上に本物の会員を足すとカオス。
- LINE に既に安定 ID があるのに、Web で別 ID を急ぐ理由が弱い。

**正しい読み**: (B) 同意サーバ化 + 属性の再ブランド → (C) LINE Login 任意。メール会員は 90 日 Won't。

**判定**: Kill（必須会員）。Keep（任意プロフィール再定義）。

---

## 主張 4: 「Sage をさらに綺麗に／プロト移植しろ」

**穴**:
- 54 は既に本番。見た目は「足りない」より「情報設計と待ち」が足りない。
- UI/ に 56 パターンあること自体が**意思決定不全の証拠**。増やすな、殺せ。
- 方向 C は未着手モック。今やってはブランド散漫。

**正しい読み**: 36/39/44/42 の 4 つだけ。あとは凍結。

**判定**: Pivot（選択移植のみ）。

---

## 主張 5: 「待ちは進捗 UI で誤魔化せ」

**穴**:
- 計画 v2 自体が「フェーズド応答は体感悪化で不採用」と言っている。
- 24s をどれだけ優しく説明しても、夜間発熱の親は離脱する。
- `LATENCY_*` を本番に出さず進捗だけ磨くのは**誠実さの欠如**。

**正しい読み**: 実測短縮を主、進捗は従。15s を公式 KPI に再合意するか、達成計画を出せ。

**判定**: Kill（進捗 alone）。Keep（進捗 + LATENCY）。

---

## 主張 6: 「アバター / VH で差別化」

**穴**:
- ロードマップ R3: 顔は遅延を増幅する。24s 沈黙＝故障。
- 薬機改正後、ビデオ指導と誤認されうる。
- デモ薬剤師ボタンが既に誤認リスクを抱えているのに、顔を足すな。

**正しい読み**: p95 と禁忌一元化と AI 明示が前提。VH は 90 日 Won't。

**判定**: Kill（今四半期）。

---

## 主張 7: 「安全は FN=0 で現状維持でよい」

**穴**:
- FN=0 文化は正しいが、**FP 害（恐怖・ケア放棄・Counseling 閉じ込め）を測っていない**のは職務怠慢（Jev F5）。
- 「現状維持」は Web pending 非対称を放置することと同義。それは安全ではない。
- 検出弱体化は禁止。だが**確認質問・再入場・説明可能性**は必須の UX 仕事。

**正しい読み**: FN 優先を崩さず、FP-harm UX を正式バックログへ。

**判定**: Pivot（現状維持 → 安全 UX 吸収）。
