# 06 PDCA 12+ サイクルログ（机上・辛口）

各サイクルに敵対視点・ペルソナ視点の Check を含む。実装は未実施（方針策定用）。

---

## Cycle 1: 「全面リデザインで勝つ」

- **Plan**: UI 方向 C＋プロト全移植で差別化
- **Do**: デザイン工数見積もり（大）
- **Check（辛口）**: Sage は既に定着。市場は見た目より信頼と速度。プロト 56 は意思決定不全。高齢ペルソナは「どこを押せばいいか」が先。
- **Act**: 全面リデザイン Kill。選択移植へ Pivot
- **判定**: **Kill**

## Cycle 2: 「会員登録でリテンション」

- **Plan**: メール会員必須
- **Do**: 登録ファネル案
- **Check**: プラポリ衝突。P1/P7 即離脱。競合の会員必須は調剤履歴があるから成立。β の目的と不一致。
- **Act**: 必須会員 Kill。任意プロフィール＋同意サーバへ
- **判定**: **Kill**（必須）/ **Pivot**（任意）

## Cycle 3: 「parity 全合わせ」

- **Plan**: Web 機能を全部 LINE に、逆も
- **Do**: 巨大ギャップ表
- **Check**: TTS on LINE は制約大。用途差（処方箋 LINE vs OTC）。安全非対称だけが本物の欠陥。
- **Act**: safety symmetry に縮小
- **判定**: **Pivot**

## Cycle 4: 「進捗 UI 強化だけで待ち解決」

- **Plan**: スピナーと文言を増やす
- **Do**: ラベル改善案
- **Check**: v2 計画がフェーズド応答を却下済み。24s は説明では消えない。P2（夜の発熱）が最厳。
- **Act**: LATENCY 本番化を主、進捗は従
- **判定**: **Kill**（alone）→ **Keep**（複合）

## Cycle 5: 「VH / アバターでデモ映え」

- **Plan**: Live2D / VRM
- **Do**: コスト・法務調査（既存あり）
- **Check**: 遅延増幅。遠隔指導誤認。薬剤師デモ誤認と二重。
- **Act**: 90 日 Won't。音声読み上げのみ将来検討
- **判定**: **Kill**

## Cycle 6: 「Safety は触るな（現状維持）」

- **Plan**: FN=0 のため UX も凍結
- **Do**: 変更禁止リスト
- **Check**: Web pending 非対称は「触らない」対象ではない。F5 FP 害は測定すらしていない。現状維持＝職務放棄。
- **Act**: 検出弱体化 No-Go を維持しつつ、確認質問・再入場・対称化は必須
- **判定**: **Pivot**

## Cycle 7: 「Emergency 確認質問ラダー」

- **Plan**: 曖昧赤旗は 1 問確認してから 119 級表示
- **Do**: 文面・状態機械案（検出は維持）
- **Check（敵対）**: 確認中に真緊急を遅らせないか？ → 高確信赤旗は即時。低確信のみラダー。再ロック必須。
- **Act**: Gate 観測軸とセットで採用
- **判定**: **Keep**

## Cycle 8: 「Counseling / SessionOps 出口」

- **Plan**: 「市販薬へ」「症状に戻る」常時 CTA
- **Do**: status カード＋pending UI
- **Check**: 危機中に OTC 誘導しすぎないか？ → 危機 OR 時は CTA 抑制。非危機のみ。
- **Act**: 条件付き Keep
- **判定**: **Keep**

## Cycle 9: 「handoff 堅牢化」

- **Plan**: Redis/DB トークン＋失効画面＋再発行
- **Do**: 設計
- **Check**: マルチインスタンス本番で今も壊れうる。P6 学生の評価を一発で落とす。優先度は見た目より上。
- **Act**: W0–W1 に入れる
- **判定**: **Keep**

## Cycle 10: 「『登録』再ブランド＋同意サーバ」

- **Plan**: 「任意プロフィール（安全のため）」＋サーバ同意ログ。会員なし
- **Do**: 文言・API・プラポリ差分
- **Check**: 「結局データ取るんでしょ」不信 → 最小項目・スキップ可・削除導線明示で緩和。
- **Act**: W2 採用
- **判定**: **Keep**

## Cycle 11: 「信頼ストリップ＋進捗ウィザード選択移植」

- **Plan**: プロト 36/39/44 のみ
- **Do**: Sage トークン内で実装設計
- **Check**: ヘッダー過密にならないか。About と役割分担。薬剤師はデモ明示。
- **Act**: W3。46 は後回し
- **判定**: **Keep**

## Cycle 12: 「本番フラグ棚卸し（届ける）」

- **Plan**: UX 十二種と SAFETY_EMERGENCY_CHANNEL_SPLIT の本番方針
- **Do**: カナリア ALLOWLIST → 全開
- **Check**: いきなり全開は危険。だが永久 OFF は「改善した嘘」。
- **Act**: カナリア 2 週間必須
- **判定**: **Keep**

## Cycle 13: 「多言語を誠実に」

- **Plan**: UI 言語＝返信言語、または「返信は日本語」を常時表示
- **Do**: 翻訳再開 or 正直ラベル
- **Check**: 今の状態は P4 にとって詐欺的。翻訳品質がダメならラベル必須。
- **Act**: まず正直ラベル、次に翻訳再開評価
- **判定**: **Keep**

## Cycle 14: 「0 件 UX の次アクション強化」

- **Plan**: 受診目安・再質問・代替カテゴリ
- **Do**: `physical_no_recommendation` 拡張
- **Check**: 既にベースあり。蕁麻疹実推奨は別トラック（データ）。
- **Act**: 文面 CTA 強化は Keep。実推奨は推奨品質トラック
- **判定**: **Keep**（UX）/ 品質は別 PDCA

## サイクル横断の学び

1. **見た目・会員・VH・全parity**は最初に殺し、安全・待ち・継続・誠実さに収束した。
2. 「触るな安全」も殺した。触るべきは検出器ではなく**回復 UX**。
3. アイデアは無限にあってよいが、90 日の Must は 8 個に圧縮しないと実行不能。
