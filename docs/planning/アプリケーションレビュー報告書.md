**レビュー日**: 2026年2月12日

**対象**: medicine-recommend（β版・限定公開）

---

## 1. アプリケーション概要

### 1.1 名称・目的

**チャット型医薬品相談ツール（medicine-recommend）** は、症状をチャットで入力すると一般用医薬品（OTC）の候補を提案し、飲み合わせ・注意点・受診の目安などをアドバイスするWebアプリケーションである。医師・薬剤師の代替ではなく、セルフメディケーションの補助ツールとして位置づけられ、**β版として専門関係者（薬剤師・登録販売者・企業・行政関係者等）向けに限定公開**されている。

### 1.2 技術スタック

| 項目 | 内容 |
|------|------|
| 言語・フレームワーク | Python 3.11, Flask, Gunicorn |
| データベース | Neon PostgreSQL（サーバーレス） |
| AI / NLP | OpenAI GPT-4o-mini（NLU補助）、ルールベース推奨（主軸） |
| 翻訳 | DeepL API（多言語対応） |
| デプロイ | Docker, GCP Cloud Run（asia-northeast1）, GitHub 連携 CI/CD |

### 1.3 アーキテクチャ概要

- **app.py**: 薄く保たれ（約89行）、Blueprint によるルート分離
- **ルート**: main_routes / admin_routes / api_routes / feedback_routes
- **ビジネスロジック**: `src/` 配下に core, handlers, services, security, analysis 等で集約
- **推奨システム**: ルールベーススコアリングを主軸とし、NLU で信頼度が低い場合のみ GPT を利用するハイブリッド方式

### 1.4 主な機能

- チャット形式の医薬品相談・トリアージ（医薬品推奨／カウンセリング／店舗案内／診断名検出／緊急事案等）
- 多言語対応（DeepL）、セッション管理（DB）、管理画面・手動返信・フィードバック
- アクセシビリティ（音声読み上げ・文字サイズ・WCAG AA）
- 不適切入力ブロック、店舗案内・緊急避妊薬案内

### 2.2 セキュリティ・入力検証

| S7 | **プロンプトインジェクション対策** | security_validator で対策済みだが、新種の攻撃パターンへの追従 | 定期的なセキュリティテスト（ペネトレーションテスト）の実施。ホワイトリスト・パターンの継続的更新 | 中 | 継続 |

## 4. まとめ

本アプリケーションは、医薬品推奨の安全性をルールベースを主軸に置き、セキュリティ（プロンプトインジェクション対策等）やアクセシビリティにも配慮した、よく設計されたシステムである。一方で、**本番運用に直結する設定（CORS、シークレットのデフォルト値、セッションストア）** と **CI/CD・テスト自動化** の整備が急務である。法規制・免責の観点では、β版であることと免責表示の明示が重要となる。

上記の改善を段階的に実施することで、安全性・運用性・保守性のいずれも向上し、一般公開に向けた基盤がさらに堅牢になると考えられる。
