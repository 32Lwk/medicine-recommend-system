## 北海道

### 地域特性（1〜2文）

全国で人口密度が最も低く（67人/km²）、過疎市町村が152/179と多数を占める広域県。1997年頃をピークに全国より約10年早く人口減少に入った。

| 指標 | 数値 | 出典 |
|------|------|------|
| 高齢化率（65歳以上） | 33.3%（全国29.3%） | [総務省統計局 人口推計 2024年10月1日](https://www.stat.go.jp/data/jinsui/2024np/index.html) |
| 総人口 | 504万3千人 | 同上 |
| 人口密度 | 67人/km²（全国338人/km²） | [北海道データブック2024 人口・生活](https://www.pref.hokkaido.lg.jp/ss/tkk/databook/193562.html) |
| 過疎市町村数 | 152市町村（2022年4月1日） | 同上 |
| 65歳以上単独・高齢のみ世帯 | 34.3%（1980年12.2%から増加） | [北海道データブック2025 保健・福祉・医療](https://www.pref.hokkaido.lg.jp/ss/tkk/databook/223727.html) |
| 人口10万人対医師数 | 264.8人（全国274.7人） | 同上 |

### 住民生活の具体的課題（3〜5 bullet）

- **広域・冬季の外出抑制**: 市部以外ではドラッグストア・薬局までの移動距離が長く、吹雪・路面凍結時は高齢者の外出自体が困難になる。
- **単独・高齢世帯の増加**: 3世代世帯が1980年37.9%→2020年5.0%に減少する一方、高齢単独世帯が拡大し、服薬相談の「見守る人」がいないケースが増えている。
- **医療・薬局の偏在**: 過疎地では薬剤師確保・薬局新規開設が困難で、厚労省もへき地の医薬品提供体制の構築を重点課題としている。
- **観光・インバウンド**: スキー・自然観光地での急な体調不良時、言語の壁がある外国人観光客への OTC 案内が現場負担になりうる。
- **デジタルデバイド**: スマホ普及は進む一方、70代の約6割が「使いこなせていない」と実感（全国調査）。

### 本サービスとの接点（1〜2文）

チャット型 OTC 相談は、冬季や広域で薬局に行けない高齢者・単身世帯が「候補と注意点を自宅で確認する」参考手段になりうる。多言語・音声読み上げは観光地での外国人にも対応可能（β版・限定試験運用）。

### デジタル化の機会（1 bullet）

- 郵便局・道内拠点とのオンライン服薬指導実証（総務省）と同様、**Web チャット＋音声**で「相談の入口」をデジタル化し、登録販売者・薬剤師の対面相談前の情報整理を支援できる。

## 青森県

### 地域特性（1〜2文）

本州最北端。人口減少率・高齢化率ともに全国上位。りんご・温泉・津軽など観光資源は豊富だが、医療・薬局人材の確保が慢性化している。

### 関連する統計・公開データ（出典 URL 必須）

| 指標 | 数値 | 出典 |
|------|------|------|
| 高齢化率 | 35.7% | [総務省統計局 人口推計 2024年10月1日](https://www.stat.go.jp/data/jinsui/2024np/index.html) |
| 人口減少率 | -1.66%（全国18県で1%超、2位） | 同上 |
| 外国人延べ宿泊者数（2024年） | 43万5,010人泊 | [国土交通省東北運輸局 2024年宿泊統計](https://wwwtb.mlit.go.jp/tohoku/content/000362851.pdf) |
| 東北6県合計高齢化率順位 | 4位（35.7%） | [日本経済新聞 2024年人口推計報道](https://www.nikkei.com/article/DGXZQOCC142LY0U5A410C2000000/) |

### 住民生活の具体的課題（3〜5 bullet）

- **人口減・若年流出**: 減少率1%超が続き、薬局・ドラッグストアの経営基盤が弱くなる。
- **高齢化と聴力・理解力の差**: 店頭での説明が届きにくい高齢者が増加（発表者のドラッグストア勤務経験とも一致）。
- **観光シーズンの言語障壁**: 津軽・十和田・奥入瀬などで外国人宿泊が回復し、体調不良時の OTC 案内需要が増える。
- **冬季・交通**: 積雪地域では外出抑制が強く、EC 購入前の「何を買うか」判断支援ニーズが高い。
- **医療アクセス**: 北東北3県と同様、過疎地の受診・薬局利用の移動コストが大きい。

### 本サービスとの接点（1〜2文）

日本語のチャット入力＋音声読み上げ（Amazon Polly）で、聴覚・理解に個人差のある高齢者の「自宅での再確認」に使える設計。英語・中国語・韓国語切替で観光客にも対応（診断・処方ではない参考情報）。

### デジタル化の機会（1 bullet）

- 青森県の観光 DMP・宿泊統計と連携した「観光客向け体調相談 QR」の将来展開（現状は β版試験）。

### 地域特性（1〜2文）

東日本大震災からの復興・産業転換期。縦長の県域で沿岸と内陸の人口分布にギャップがあり、北東北3県の人口減少が顕著。

| 2050年高齢化率推計 | 45.9% | [令和7年版高齢社会白書 表1-1-10](https://www8.cao.go.jp/kourei/whitepaper/w-2025/html/zenbun/s1_1_4.html) |

### 住民生活の具体的課題（3〜5 bullet）

- **広域・過疎**: 内陸・沿岸の過疎地域では薬局までの距離・営業時間の制約が大きい。
- **高齢単身世帯**: 東北全体で単独世帯化が進み、服薬ミス・残薬リスクへの警戒が必要。
- **観光（平泉・盛岡）**: 2024年東北の外国人宿泊は2019年比1.24倍の過去最多。急な風邪・胃腸症状での OTC 需要。
- **季節要因**: 冬季のインフルエンザ・風邪、花粉シーズンの対症療法薬選びの相談需要。
- **人材不足**: 登録販売者・薬剤師の確保が店頭相談のボトルネックになりうる。

### 本サービスとの接点（1〜2文）

ルールベース OTC 推奨＋危険症状時の受診勧奨は、過疎地で「まず自宅で判断材料を得る」際の一助になる。チャット形式なら専門用語がなくても症状を伝えられる。

### デジタル化の機会（1 bullet）

- 復興関連のデジタルインフラ整備と合わせ、**スマホからの OTC 参考相談**を在宅・単身世帯のセルフメディケーション支援として位置づけ可能。

## 宮城県

### 地域特性（1〜2文）

仙台を中心とする東北最大の都市圏。高齢化率は6県中で相対的に低いが、県全体では過疎地も残る。インバウンド回復が著しく、外国人宿泊が県の宿泊伸びを牽引している。

| 外国人延べ宿泊者数（2024年） | 76万9,540人泊（東北6県中最大） | [国土交通省東北運輸局](https://wwwtb.mlit.go.jp/tohoku/content/000362851.pdf) |
| 仙台市内訪日外国人宿泊者 | 2019年比126%（2024年） | [仙台観光動向レポート 2024](https://www.sentia-sendai.jp/sentiasys2/wp-content/uploads/2024/12/9ce97a45af31783c09b3e85a919fcd4b2.pdf) |

### 住民生活の具体的課題（3〜5 bullet）

- **都市部と過疰の二極化**: 仙台圏はアクセス良好だが、県北・県南の過疎地では薬局・夜間対応が課題。
- **インバウンド急増**: 空港国際線復便・増便で外国人の急な体調不良・言語障壁が現場課題に。
- **少子高齢化の加速**: 生産年齢人口減により、店頭相談を担う人材確保が長期的に厳しい（知事も外国人材受入れ言及）。
- **EC・セルフメディケーション**: 都市部ではオンライン購入が増え、購入前の適切な選び方支援が不足しがち。
- **デジタル活用**: 仙台市の観光 DMP 等、デジタル基盤は整いつつあるが、医薬品相談のデジタルサービスは限定的。

### 本サービスとの接点（1〜2文）

Amazon Translate による英語・中国語・韓国語対応は、仙台観光地での外国人向け OTC **参考**案内に直結。AWS ステージング（`aws.medicine.yutok.dev`）で本番同等の多言語フローをデモ可能。

### デジタル化の機会（1 bullet）

- 観光協会・宿泊施設への「体調相談 QR」設置（将来）。現 β版は専門関係者向け試験運用。

- **超高齢社会**: 2人に1人弱が高齢者に近づく構造で、服薬・OTC 選びの支援需要が極めて高い。
- **薬局・医療のアクセス**: 過疎地では移動・営業時間の制約が大きく、セルフメディケーションの「自己判断」負担が増える。

- **若年・生産年齢人口の減少**: 店頭で相談を受ける人材自体が減る構造。

### 本サービスとの接点（1〜2文）

文字サイズ調整・音声読み上げ・WCAG AA コントラストなど、高齢者向けアクセシビリティを標準装備。ルールベース推奨でハルシネーション（薬名の創作）を抑制し、安全性を重視（医療行為ではない）。

- 秋田県の福祉・医療 DX と連携した「在宅高齢者向け OTC 参考チャット」（将来）。現状は β版で専門家フィードバック収集中。

## 本サービスが刺さるペルソナ3例

### ペルソナA — 過疎地の高齢単独世帯（例: 秋田県内陸、75歳女性）

- **課題**: 雪で薬局に行けない。聴力が弱く店頭説明が聞き取りにくい。何を買えばよいか不安。
- **接点**: 日本語チャット入力 → ルールベース OTC 候補 → **音声読み上げ（Polly）**で再確認。重い症状は受診勧奨。
- **免責**: β版・参考情報。必ず薬剤師・医師に相談。

### ペルソナB — 仙台観光中の訪日外国人（例: 台湾から個人旅行、30代）

- **課題**: 急な喉の痛み。日本語が読めない。近くのドラッグストアで何を買うかわからない。
- **接点**: 英語入力 → **Amazon Translate** → 日本語処理 → 英語表示。軽症 OTC 候補と注意点。
- **免責**: 診断・処方ではない。重篤時は医療機関へ。

### ペルソナC — ドラッグストア勤務の登録販売者（例: 岩手県、40代）

- **課題**: ピーク時に相談が集中。高齢者・外国人への説明に時間がかかる。
- **接点**: β版を**来店前・購入前の参考ツール**として顧客に案内し、店頭相談の事前整理を支援（一般公開ではない試験運用）。
- **免責**: 本ツールは人の相談を代替しない。最終判断は専門家。
