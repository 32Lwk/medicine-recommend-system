## 想定 Q&A 10問

### Q1. なぜ名古屋の学生が北海道・東北ブロックなのですか？

**A**: 大会のテーマが7県横断の課題設定であり、プロダクトは地域を限定しない Web サービスだからです。統計と文献で7県を調査し、過疎・高齢化・インバウンドという共通課題に応える設計にしています。

### Q2. これは医療 AI ですか？診断しますか？

**A**: **いいえ。** 医療機関・診断サービスではありません。一般用医薬品の候補と受診目安など**参考情報**を提供する β版です。薬剤師・医師の代替ではなく、重い症状は受診を勧めます。

### Q3. 薬の推奨精度はどう保証しますか？

**A**: 薬名選定は **ルールベーススコアリング**（症状辞書・CSV マスタ・年齢・相互作用等）が中核で、LLM が薬名を決定しません。ハルシネーション抑制を意図した設計です。β版では専門家からフィードバックを収集しています。

### Q4. なぜ本番は GCP で AWS はステージングだけですか？

**A**: 本番の DeepL・Google TTS の安定性を保ちつつ、AWS ネイティブ（Translate / Polly / Bedrock KB）を安全に試験するため、意図的に分離しています。同一 Docker イメージ・機能フラグのみの差分です。

### Q5. AWS のコストは払えますか？学生でも運用可能ですか？

**A**: AWS Budgets と Lambda 段階的アクションで予算超過時に ECS を縮小・停止します。ステージングは試験用途で、デモ前に `resume-aws-staging.sh` で起動する運用です。

### Q6. 一般公開はいつですか？

**A**: **未定・検討段階**です。現状は薬剤師・行政・研究関係者など限られた専門家向け β版試験運用です。一般消費者向け正式公開は、安全性と法規制を踏まえ今後検討します。

### Q7. 競合（例: 薬局アプリ、Google 検索）との差は？

**A**: (1) ルールベース中心の安全設計、(2) 多言語＋音声＋アクセシビリティ一体、(3) マルチエージェントで症状相談と FAQ を分離、(4) AWS/GCP クロスクラウドで地域展開しやすい、が差別化です。

### Q8. 7県のうち特定県向けにカスタマイズしていますか？

**A**: 現 β版は全国共通の OTC マスタと UI です。7県調査は課題設定の根拠であり、県別の行政連携データ連携は将来フェーズです。

### Q9. 個人情報・症状データはどう扱いますか？

**A**: 入力は匿名化設計で、薬提案以外の目的では使わない方針です。AWS ステージングと GCP 本番は **別 DB インスタンス**です。詳細はプライバシーポリシー（リポジトリ `docs/public/`）に準拠。

### Q10. デモが動かなかった場合、実装は本当にありますか？

**A**: 同一 URL のステージングは Budget 等で ECS が停止している場合があります（503）。アーキテクチャは CLI 確認済みの実リソースで、CodePipeline で GitHub main からデプロイ可能です。フォールバック録画・draw.io 図を用意します。
