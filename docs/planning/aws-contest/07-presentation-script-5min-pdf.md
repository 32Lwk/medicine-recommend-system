### page 10 — AWS構成・アーキテクチャ図（25秒）

**指差し**: ① User（Browser＋LINE）→ ② WAF/ALB/ECS → ③ PMDA／医薬品DB → ④ Translate・Polly・Bedrock KB

> こちらが **AWS構成** です。**aws.medicine.yutok.dev**、東京リージョン。  
> 図の左、**Browser** と **LINE** — 高齢者や外国人の方にとって、**LINE は馴染みやすい入口** です。本日のデモは Browser 経路、本番 LINE も **同一 Docker・同一ロジック** です。  
> 入力は **WAF → ALB → ECS Fargate** でアプリが動き、JS/CSS は **CloudFront＋S3** です。  
> **ここがポイント** — 医薬品データはすべて **国の機関 PMDA** の情報に基づき、**正しい根拠データ** で提供しています。候補選定はこのDBをルールベースで参照し、**LLM は医薬品には関わりません**。  
> **Translate**・**Polly**・**Bedrock KB** が、多言語・音声・FAQ を担当します。

**操作**: ① User ブロックの **LINE アイコン** を指す → ② WAF 矢印 → ③ **PMDA** を強調。点線（Personalize 等）は触れない。

**LINE の話し方（本スライドに集約）**

| 触れる | 触れない |
|--------|----------|
| 図どおり「Browser と LINE の2入口」 | LINE Webhook が AWS ECS を向いている（本番は GCP） |
