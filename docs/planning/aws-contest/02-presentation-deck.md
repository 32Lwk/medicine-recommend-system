## スライド 2 — テーマ選択（20秒）

### 画面文言

- なぜ「住民の暮らしを豊かに」か
- セルフメディケーション需要 ↑ / 相談機会 ↓（過疎・高齢化）
- 7県共通: 「適切な市販薬を選ぶ」日常の不安
- ドラッグストア現場で実感したギャップ

### スピーカーノート

テーマ2を選んだ理由は、薬は毎日の暮らしに直結するからです。OTC市場は拡大していますが、秋田のように高齢化率39%の地域では、薬局に行けない・相談できない人が増えています。私自身のドラッグストア勤務で、高齢者の聴力差や外国人の言語の壁を実感しました。

### 審査対応

地域理解 — テーマと現場経験の接続。

## スライド 3 — 7県の課題概要（45秒）

### 画面文言

- **7県マップ** + 共通3アイコン: 高齢化 / 過疎 / 言語の壁
- 高齢化率: 秋田 **39.5%**（全国1位）〜 宮城 29.6%
- 東北外国人宿泊 **229万人泊**（2024・2019比1.24倍）
- 冬季・広域 → 外出・店頭相談が困難
- 出典: 総務省人口推計 / 国交省東北運輸局

### スピーカーノート

7県それぞれに違いはありますが、共通課題は三つです。一つ目、全国トップクラスの高齢化。二つ目、過疎地での薬局・医療アクセス。三つ目、観光復活に伴う外国人の言語障壁。北海道は152の過疎市町村、宮城は仙台を中心に外国人宿泊が過去最多水準です。これらは「デジタルで相談入口を増やす」余地があります。

### 審査対応

地域理解・インパクト — 7県を均等に触れ、統計に出典。

## スライド 4 — 課題の深掘り（40秒）

### 画面文言

- 現場エピソード: 高齢者が説明を聞き取れない
- 外国人客「Which medicine?」→ 店員も助け合い必要
- 70代の約6割がスマホ「使いこなせていない」実感
- でも60代の78%はスマホでネット接続 — **入口はある**
- 必要なのは: やさしい UI + 音声 + 多言語

### スピーカーノート

具体例を一つ。店頭で説明しても聞き取れず、同じ質問を何度もされる高齢のお客様。一方、外国人の方は英語で症状を伝えても、OTCの棚は日本語だけ。スマホは普及していますが、使いこなしには課題も残ります。だから音声読み上げ、文字サイズ調整、4言語対応を標準にしました。

### 審査対応

アイデアのリアリティ — 現場エピソードとユーザー像。

## スライド 5 — ソリューション（40秒）

### 画面文言

- **チャット型 OTC 参考相談**（β版）
- ハイブリッド AI: **ルールベース選薬** + LLM は NLU・説明のみ
- 機能: 症状チャット / 多言語 / 音声 / 受診勧奨
- マルチエージェント: Triage → Physical / Concierge
- ⚠ 医療機関・診断サービスではない

### スピーカーノート

medicine-recommend は、症状をチャットで入力すると一般用医薬品の候補と注意点を返すツールです。薬の選定はルールベースが中核で、LLMが薬名を創作しない設計です。危険な症状は受診を勧めます。対象は現状、薬剤師や行政関係者など限られた専門家向けのβ版試験運用です。

### 審査対応

プロダクト・テクノロジー + リアリティ — 正本どおりの機能説明と免責。

## スライド 6 — AWS アーキテクチャ（40秒）

### 画面文言

- デモ: **aws.medicine.yutok.dev**（AWS ステージング）
- User → **WAF → ALB → ECS Fargate**
- **Translate** 多言語 / **Polly** 読み上げ / **Bedrock KB** FAQ
- CloudFront + S3 / CodePipeline CI/CD
- 本番 GCP + AWS 試験 = **同一 Docker・機能フラグ**

### スピーカーノート

デモ環境は AWS 東京リージョンです。WAFとALBの後ろでECS Fargateが動き、Translateで翻訳、Pollyで音声、Bedrock Knowledge BaseでConciergeのRAGを試験しています。本番はGCPで安定運用、AWSはネイティブ機能の検証用。コードは同一で、環境変数だけ切り替えます。

### 審査対応

プロダクト・テクノロジー — AWS サービス名の正確な列挙。

**図**: [`docs/ops/AWS_ARCHITECTURE_DIAGRAMS.md`](../../ops/AWS_ARCHITECTURE_DIAGRAMS.md) の Mermaid 簡略版をスライドに貼付。

## スライド 8 — インパクト・展開（30秒）

### 画面文言

- **対象**: 高齢者 / 訪日外国人 / 過疎地住民 / EC 購入者
- **展開**: 7県 → 全国（機能フラグで GCP/AWS 選択可）
- **持続性**: マネージド AWS + Budget 段階停止
- **将来**: 自治体・薬局 QR、Personalize（Phase 4）
- 一般公開は検討段階（現 β版）

### スピーカーノート

対象者は広く、北海道の過疎地から仙台の観光客まで同じ Web 入口で参考相談できます。クラウドを替えても同じ Docker が動くので、他地域展開のハードルは低いです。一般公開はこれからですが、専門家向けβ版で安全性とUIを検証中です。

### 審査対応

課題解決のインパクト — 対象の広さと持続可能性。
