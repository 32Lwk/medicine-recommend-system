フェーズ概要

  • キックオフ — 環境・リポジトリ整理、既存テスト・CI確認、9ヶ月計画の詳細化、PM・IPAとのキックオフ
  • Phase1 潜在空間 — 医薬品効能のベクトル化（埋め込みAPI利用）、コサイン類似度、ルールベース並行評価用IF
  • Phase2 ハイブリッド統合 — 重み・動的重み設計、ハイブリッドスコアリング実装、5層防御結合
  • 検証・Phase3 — 安全性検証、A/B評価、重みチューニング、評価レポート
  • 仕上げ — ドキュメント整備、デモ動画、成果・実績報告書
  • 専門家監修 — Phase1完了時・統合テスト前・Phase3評価前など、一定の完成段階で薬剤師・登録販売者等に監修依頼
