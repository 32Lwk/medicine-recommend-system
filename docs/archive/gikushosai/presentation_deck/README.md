| `02-problem.png` | 課題・背景 | `slide02-problem-A.png` |
| `03-solution.png` | ハイブリッド解決策 | `slide03-solution-D.png` |
| `04-demo.png` | デモ・UI | `slide04-demo-A.png` |
| `05-scoring.png` | スコアリング | `slide05-scoring-C.png` |
| `06-pipeline.png` | SSE・リアルタイム応答 | `slide06-pipeline-E.png` |
| `07-multiagent.png` | マルチエージェント分岐 | `slide07-multiagent-B.png` |
| `08-safety.png` | 緊急対応・OTC政策 | `slide08-safety-D.png` |
| `09-techstack.png` | フロント/バック構成 | `slide09-techstack-D.png` |
