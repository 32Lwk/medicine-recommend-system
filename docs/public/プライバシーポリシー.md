🔒 プライバシーポリシー（試験運用版）

第1条（基本方針）
本アプリ「チャット型医薬品相談ツール」は、試験運用（βテスト）段階において、テスターから得られた情報を適切に取り扱い、個人情報保護法および関連法令を遵守します。
テスターのプライバシーを尊重し、安全で信頼できる環境の提供に努めます。

第2条（取得する情報）
本アプリでは、試験運用の目的で以下の情報を収集する場合があります。
1.ユーザー入力情報（症状、年齢層、性別、アレルギー、併用薬など）
2.利用履歴・アクセスログ・利用日時・エラー情報等
3.LINE 連携利用時の情報（ユーザー識別子を LINE userId のまま保存せず、ハッシュ化または仮名 ID として扱うもの、相談内容の要約、属性情報の長期保存、Web ブラウザへの引き継ぎ用の短期トークン）
4.アンケートやフィードバックフォームへの回答内容
※氏名・住所・電話番号など、個人を直接特定できる情報は、原則として収集しません。

第3条（利用目的）
収集した情報は、次の目的に限り利用します。
・本アプリの精度向上・不具合修正・機能改善のため
・LINE 等での継続相談時に、過去の相談要約と属性情報を参照して安全性・提案品質を高めるため
・Web ブラウザへの引き継ぎにより、相談内容を継続するため
・テスト結果の分析および開発報告資料の作成のため
・運営上必要な連絡（バグ報告、改善依頼など）のため

第4条（第三者提供）
運営者は、以下の場合を除き、取得情報を第三者に提供しません。
・法令に基づく場合
・本人の明確な同意がある場合

第5条（情報の管理と削除）
1.取得情報は、不正アクセス・漏洩・改ざん等が起こらないよう、適切な技術的・組織的措置を講じ、安全な環境で管理します。
2.LINE 連携による長期記憶（属性情報・相談要約等）は、相談継続および安全性向上のため一定期間保持します。利用者はチャット上での削除依頼、または第7条の連絡先から、開示・訂正・削除を請求できます。
3.試験運用の終了または本アプリの提供停止時には、法令上保存が必要な場合を除き、個人を特定しうる情報は速やかに削除または匿名化します。

第6条（匿名加工情報の取り扱い）
1.運営者は、利用者から取得した情報のうち、個人を特定できないように加工した「匿名加工情報」を作成する場合があります。
2.匿名加工情報は、個人を特定できない形式で統計処理・サービス改善・学術的検討などの目的で利用することがあります。
3.匿名加工情報を第三者に提供する場合は、再識別できない形式を維持し、適切な安全管理措置を講じます。
4.匿名加工情報の作成および提供に関する方針が変更された場合には、本ポリシー内で速やかに公表します。

テスターは、自身に関する情報の開示・訂正・削除を請求できます。
1.LINE 連携利用時は、チャット内で相談記憶・属性情報の削除を依頼できます。
