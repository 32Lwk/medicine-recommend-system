# アプリ概要（β版・限定公開）

本アプリは、研究開発中の**β版（試験運用版）**として運用されています。  
対象は、企業・行政関係者・薬剤師・登録販売者など限られた専門関係者に限定し、**非営利・学術目的**で公開しています。

独自のルールベースアルゴリズムと大規模言語モデル（LLM）を組み合わせた**ハイブリッド推奨システム**により、ユーザーの症状・体調・生活状況に基づいて一般用医薬品（OTC薬）をチャット形式で提案し、誰もが安心してセルフメディケーションの参考にできる環境の実現を目指しています。

---

## 開発背景

少子高齢化、訪日外国人増加、ECサイトの普及により、セルフメディケーションの需要は高まっています。一方で、言語の壁や人材不足により、利用者が適切な医薬品を選べず安全性が懸念されているのが現状です。

開発者自身のドラッグストア勤務経験から、高齢者の聴力・理解力の差や外国人との言語障壁を実感したことをきっかけに、薬学的知識とLLMを融合した**チャット型医薬品相談ツール**として本システムを構想しました。

本β版は、これらの課題解決に向けた実証研究・検証を目的とした**限定的運用**です。

---

## 利用目的

- **本β版の目的**: AIを用いた医薬品相談のUI/UXおよび独自選定アルゴリズムの有効性について、専門家の皆様からフィードバックをいただくこと。
- 利用者が自身の症状を正しく伝え、適切な一般用医薬品を**安全に選択する一助**となるよう支援する。
- チャット形式で症状に合った市販薬の候補や受診の目安を提示し、セルフメディケーションの推進を図る。
- 薬局来店前・オンライン購入前の**参考情報**としての活用を想定。医療機関への早期受診判断を助ける機能を持つ。

**本アプリは医師・薬剤師の診断や指導を代替するものではなく、利用者の安全な判断を補助する情報提供ツールです。**

## 対象者（β版）

**【本β版の対象者（テスター）】**

- 薬剤師・登録販売者などの医薬専門職
- 医療・行政・研究機関に所属する関係者
- 医薬品販売やセルフメディケーション支援に関心のある企業担当者

別途、研究の一環として将来の想定利用者（一般消費者・訪日外国人など）へのユーザーヒアリングにご協力いただく場合があります（本β版の一般公開を意味するものではありません）。

※ 一般消費者向けの正式公開は検討段階であり、本β版は評価・検証を目的とした非公開試験です。

**【将来的な想定利用者】**  
（実用化された場合の例）

- どの薬を選べばよいかわからない一般消費者
- 忙しくて薬局に行けない人や過疎地域の住民
- 言語の壁で相談が難しい訪日外国人
- 高齢者や聴覚・理解力に個人差のある方
- EC・オンライン薬局で購入を検討する利用者

## 主な特徴

| 項目 | 内容 |
|------|------|
| **相談形式** | 自然なチャット形式。専門知識がなくても会話のように症状を入力するだけで候補を提示。 |
| **安全性** | 医薬品DB・薬学的知識・AIを組み合わせた安全設計。誤情報抑制のためのルールベース推奨を中核に据え、LLMは補助的に利用。 |
| **受診勧奨** | 危険な症状や重篤な疾患が疑われる場合には、医療機関受診を自動推奨。 |
| **多言語** | **日本語・英語・中国語・韓国語**に対応（DeepL API による高速翻訳）。 |
| **多環境** | スマートフォン・タブレット・PC（iOS / Android / Windows / macOS / Chrome / Safari 等）で利用可能。 |
| **アクセシビリティ** | 音声読み上げ、文字サイズ調整、セクション折りたたみ、WCAG AA 準拠のコントラストなど、高齢者・障害者に配慮したUI。 |
| **データ管理** | 入力情報は匿名化し、薬提案以外の目的では利用しない設計。プライバシーを最優先。 |

---

## 強み・差別化

- **AI と独自アルゴリズムの併用**により、安全性と柔軟な言語理解を両立。
- **薬学的根拠に基づいた提案**と自然言語理解（NLU）の融合。
- 現場課題（人手不足・言語の壁・情報格差）への直接的アプローチ。
- 誰でも使いやすいUI設計による導入の容易さ。

---

## 独自アルゴリズム

医薬品選定の中心となる**ルールベース推奨**は、症状辞書・効能特異性・年齢適合性・副作用・相互作用・症状特異性ペナルティなどを統合的に評価する独自スコアリングで構成されています。LLM は症状抽出（NLU）の補助や質問生成などに限定し、**薬の選定はルールベースで一貫して行う**ことで、根拠に基づいた提案とハルシネーション抑制を実現しています。回答には出典・注意喚起を付与し、利用者が自ら判断できる設計としています。

## 開発環境・使用ツール

| 分類 | 技術 |
|------|------|
| **バックエンド** | Python 3.9+, Flask 3.0.0, Jinja2 |
| **AI/NLP** | OpenAI GPT-4o-mini、ルールベース NLU（ハイブリッド推奨） |
| **翻訳** | DeepL API（日・英・中・韓、高速翻訳） |
| **データベース** | Neon PostgreSQL（セッション・フィードバック・グローバル状態、マルチインスタンス対応） |
| **データ処理** | Pandas, NumPy |
| **フロントエンド** | HTML5, CSS3, JavaScript（ES6+）・バニラJS（フレームワーク不使用）、レスポンシブ・モバイルファースト |
| **セッション** | Flask Session（自動復旧） |
| **監視・ログ** | psutil, JSONL 構造化ログ、アクセス分析・パフォーマンス・セキュリティ監視 |
| **デプロイ** | GCP Cloud Run（Docker）、Gunicorn（WSGI） |
| **テスト** | Python unittest ベース（統合・単体テスト） |
