本計画は、アプリケーションレビューおよび医師の観点からの指摘事項を踏まえ、具体的なタスクに落とし込んだ改善計画である。

| 優先度 | 項目 | 概要 | 工数目安 |

## 2. 各項目の詳細

### 2.1 【高優先度】「15歳以上以上」の重複表現を修正（1-A）

**現状の原因**

- `src/handlers/chat/chat_recommendation_flow.py` 2256–2259 行付近
- `age_restriction` が「15歳以上」の場合、「歳以上の方が対象です」を含まないため else 節に入る
- 表示時に `{age_restriction}以上の方が対象です。` と結合し、「15歳以上以上の方が対象です。」となる

**修正方針**

- `age_restriction` が「〇歳以上」を含む場合、「以上の方が対象です」は付けず、「〇歳以上の方が対象です。」として表示する
- 例：`age_restriction` が「15歳以上」→「15歳以上の方が対象です。」に統一

**該当箇所（想定）**

- `chat_recommendation_flow.py` の usage_notes パース部分（年齢制限の整形処理）

---

### 2.2 【高優先度】頭痛時にカロナール（アセトアミノフェン）を第一選択として優先（1-B）

**背景**

- アセトアミノフェンは頭痛・発熱の第一選択として推奨されている
- 現状、カロナール／タイレノールにはボーナスがあるが、イブプロフェン系が上位になりやすいケースがある

**確認・対応方針**

- CSV データでカロナールA の効能が「生理痛」のみになっていないか確認
- `final_score_calculator.py` のボーナス値や、頭痛専用の加算ロジックを見直し
- 頭痛・発熱の場合はアセトアミノフェン系をより強く優先するよう調整

---

### 2.3 【高優先度】2位・3位に同成分の医薬品を並べない（1-C）

**現状**

- `ensure_ingredient_diversity`（`src/core/recommendation/ingredient_diversity.py`）で成分の多様性を考慮している
- イブプロフェン錠200S とイブプロフェン錠200SC のように、同成分・類似剤形が 2 位・3 位に並ぶケースがある

**対応方針**

- `extract_main_ingredients` や成分類似度の判定を強化
- 主成分が同一の医薬品（例：イブプロフェンのみ）が 2 位・3 位に並ばないよう、`ensure_ingredient_diversity` 内で除外・置換するロジックを追加
- 「イブプロフェン錠200S」と「イブプロフェン錠200SC」のような類似剤形を同一成分グループとして扱う

---

### 2.4 【中優先度】HTML・テキストのタイポ修正（2-A）

**現状**

- 現行コードベースでは `usage-notes-conteent`、`classs=` などのタイポは検出されなかった
- すでに修正済みの可能性、またはフロントエンド・静的ファイル側にある可能性

**対応方針**

- フロントエンド・静的 HTML を含め、プロジェクト全体で同様の typo を検索し修正
- 修正後は簡単な typo チェック用スクリプトやリントの導入を検討

---

### 2.5 【中優先度】医薬品名の表記ゆれ（半角・全角）の統一（2-B）

**背景**

- 「イブプロフェン」と「イブプロフェン」、「錠」と「錠」など、半角・全角が混在している可能性がある
- CSV、コード内のマッピング、表示ロジックのいずれにも影響する

**対応方針**

- CSV とコード内での医薬品名の正規化ルールを定義
- 必要に応じて `normalize_text` 等を活用し、比較・表示時に統一した表記を使用

---

### 2.6 【低優先度】ロキソニン・バファリンを頭痛推奨の上位候補として検討（3-A）

**背景**

- ロキソニンS、バファリンA 等は頭痛でよく利用される医薬品
- 現状のボーナス・スコアでは上位に出にくいケースがある可能性

**対応方針**

- 頭痛症状時に、ロキソニン・バファリンに十分なボーナスが付与されているか確認
- 必要に応じて `MAJOR_ANALGESIC_MEDICINES` や `final_score_calculator.py` のボーナス値を調整

## 3. 実施順序（推奨）

```
Phase 1（即時対応）
  └── 1-A: 「15歳以上以上」の修正

Phase 2（短期）
  └── 1-B: カロナールを頭痛の第一選択として優先
  └── 1-C: 成分多様性の強化（同成分の 2 位・3 位並びの回避）

Phase 3（中期）
  └── 2-A: HTML・テキストのタイポ修正
  └── 2-B: 医薬品名の表記ゆれ統一

Phase 4（随時）
  └── 3-A: ロキソニン・バファリンの上位推奨検討
```

## 4. 確認・判断が必要な点（質問）

以下の点について、方針の確認や追加情報があると計画を具体化しやすいです。

1. **「15歳以上以上」の表示元**
   - usage_notes のパース部分（`chat_recommendation_flow.py`）だけでなく、`explanation_generator.py` や他モジュールでも同様の表記がありうるか、一括で修正してよいか。

2. **成分多様性の厳格さ**
   - 「イブプロフェン200S」と「イブプロフェン200SC」を完全に同一成分として扱うか、それとも類似成分として扱い、閾値を設けて制御するか。どちらの方針を優先したいか。

3. **カロナールA の効能データ**
   - `data/otc_medicine_data.csv` でカロナールA の効能が「生理痛」のみになっていないか、現状の CSV の構造・値に制約があれば共有いただきたい。

4. **HTML タイポの発生箇所**
   - `usage-notes-conteent`、`classs=` 等が以前存在していた場合、フロントエンドの HTML／静的ファイル／別リポジトリの可能性はあるか。既知の発生箇所があれば共有いただきたい。

5. **表記ゆれの統一方針**
   - 医薬品名は「全角に統一」「半角に統一」のどちらを標準とするか、あるいは既存の仕様・運用ルールがあれば教えていただきたい。

6. **スケジュール・リソース**
   - 各 Phase の目安期間や、同時に着手可能な人数（担当者）に制約があれば共有いただきたい。

## 6. HTML タイポ検索手順

プロジェクト内で HTML・テキストの typo を検索する際は、以下の grep コマンド（または ripgrep）を使用する。

### 検索対象パターン

- `conteent`（正: content）
- `classs=`（正: class=）
- `ddiv`（正: div）
- `contraindiccation`（正: contraindication）
- `usage-notes-conteent`（正: usage-notes-content）

### 検索対象ディレクトリ

- `src/`（Python、HTML 生成コード）
- `templates/`（HTML テンプレート）
- `static/`（静的ファイル）
- フロントエンド・別リポジトリの静的 HTML がある場合は別途検索

### grep 例（ripgrep）

```bash
rg -l "conteent|classs=|ddiv|contraindiccation|usage-notes-conteent" .
```
