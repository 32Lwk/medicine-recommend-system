# 論文提出について

## 一般的な論文提出形式

### 1. PDF形式での提出（最も一般的）

**ほとんどの学会・コンクールではPDF形式での提出が標準です。**

- ✅ **LaTeXで作成したPDFを提出**: 最も一般的
- ✅ **Wordで作成したPDFを提出**: 一般的
- ✅ **手書きをスキャンしたPDF**: 一部のコンクールで可能

### 2. LaTeXソースファイルの提出

一部の学会・コンクールでは、以下を提出する場合があります：
- LaTeXソースファイル（`.tex`）
- 生成されたPDFファイル
- 使用した図表ファイル

### 3. オンライン提出システム

多くの学会・コンクールでは、オンライン提出システムを使用します：
- PDFファイルをアップロード
- 必要に応じてLaTeXソースファイルもアップロード

## LaTeXの利点

### なぜLaTeXを使用するのか

1. **美しい数式表現**
   - 数式が美しく表示される
   - 論文に適したフォーマット

2. **一貫性のある書式**
   - 自動的に書式が統一される
   - 見出し、参考文献などのスタイルが一貫

3. **バージョン管理**
   - ソースファイルで管理できる
   - 変更履歴を追跡しやすい

4. **学術界の標準**
   - 多くの学術論文で使用されている
   - 国際的な標準フォーマット

### LaTeX vs Word

| 項目 | LaTeX | Word |
|------|-------|------|
| 数式 | 美しい | やや劣る |
| 書式の一貫性 | 自動 | 手動調整が必要 |
| 学習コスト | 高い | 低い |
| 学術界での使用 | 標準 | 一般的 |
| 提出形式 | PDF | PDF |
