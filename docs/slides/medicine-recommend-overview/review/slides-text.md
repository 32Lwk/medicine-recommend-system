薬と法令の言葉
市販薬
OTC医薬品・一般用医薬品
処方箋なしで薬局・ドラッグストアで買える薬 詳しくp.4
第1類・第2類・第3類
リスク区分
市販薬の分類。第1類は薬剤師の書面での説明が義務、第2類は努力義務、第3類は定めなし 詳しくp.51
登録販売者
第2類・第3類の市販薬を売れる資格を持つ人 詳しくp.51
禁忌
その人には使ってはいけない条件（年齢・妊娠・持病・飲んでいる薬など） 詳しくp.37
解熱鎮痛薬（NSAIDs）
エヌセイズ
イブプロフェン・ロキソプロフェンなど。血を固まりにくくする薬と重ねると出血の危険が増える 詳しくp.40
ワルファリン
血を固まりにくくする処方薬。飲み合わせに特に注意が要る 詳しくp.40
添付文書
薬の効能・用法・注意を書いた公式の文書 詳しくp.42
PMDA
医薬品医療機器総合機構
薬の審査・安全の情報を扱う公的な機関。添付文書を公開している 詳しくp.42
薬機法
医薬品医療機器等法
薬の製造・販売・広告などを定める法律 詳しくp.51
しくみの言葉
AI（大規模言語モデル）
LLM
文を読み書きするモデル。ここでは症状の読み取りと説明文にだけ使う 詳しくp.34
しくみの言葉
振り分け
トリアージ
相談を緊急・体の症状・気持ち・質問・その他の5つに分けること 詳しくp.10
意図の判定
IntentRouter
推薦・比較・質問のどれを求めているかを決める段 詳しくp.32
Jev
意図の判定を外部の軽いモデルに替える試験で使ったモデル。本番には入れていない 詳しくp.48
P95（遅い側）
100回のうち遅い方から5回目の応答時間。待たされる人の体感に近い 詳しくp.49
Cloud Run
Google Cloud のコンテナを動かすサービス。本番で使う 詳しくp.29
ECS Fargate
AWS のコンテナを動かすサービス。検証環境で使う 詳しくp.30
Cloudflare Tunnel
外から直接つながずに、サーバーを公開する仕組み 詳しくp.30
Lambda・EventBridge
AWS の小さな処理と定期実行。検証環境の起動と停止に使う 詳しくp.30
SaaS・API
ネット越しに機能を貸す形。商用化の案の1つ（未定） 詳しくp.22
PolyForm Noncommercial
非商用の利用だけを認めるライセンス。商用には別の許可が要る 詳しくp.53
