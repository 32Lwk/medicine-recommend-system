### 2. CSVデータの活用（E〜K列）

| 列 | 内容 | 活用方法 |
|---|------|---------|
| E列 | 効能効果 | ChatGPTで要約 |
| F列 | 用法用量 | 使用上の注意に含める |
| G列 | 年齢制限 | **個別に表示**（例：15歳未満の方は使用しないでください） |
| H列 | 成分 | 推奨理由と使用上の注意に含める |
| I列 | 禁止物質あり | ドーピング情報として表示 |
| J列 | 競技会区分 | ドーピング情報として表示 |
| K列 | 条件 | 使用上の注意に含める |

### 3. 年齢制限の個別表示

**実装内容:**
- G列の数値を取得
- 「○○歳未満の方は使用しないでください」と表示
- G列がない場合は年齢制限を表示しない

**表示例:**
```python
if age_restriction:
    if '15歳未満' in age_restriction:
        → "年齢制限: 15歳未満の方は使用しないでください。"
    elif '7歳未満' in age_restriction:
        → "年齢制限: 7歳未満の方は使用しないでください。"
    else:
        → 表示しない
```

### 4. 不足情報の追加質問（推奨後に表示）

**優先度別の質問:**
- **Critical（必須）**: 年齢、症状 → 推奨後に表示
- **Important（重要）**: 妊娠・授乳状態 → 推奨後に表示  
- **Optional（任意）**: 期間、アレルギー → 推奨後に表示

**表示例:**
```
❓ 追加でお伺いしたいこと（優先度: 任意）
より安全な使用のため、可能であれば以下の情報を教えてください：

1. 症状はいつ頃から続いていますか？（例：昨日から、3日前から）
2. 薬や食品のアレルギーはありますか？（ある場合は具体的に教えてください）
```

## 🔧 実装の詳細

### ChatGPTプロンプト（個別医薬品の使用上の注意生成）

```python
prompt = f"""
あなたは登録販売者です。以下の医薬品情報から、使用上の注意を簡潔に生成してください。

【医薬品情報】
製品名: {製品名}
効能効果（E列）: {E列データ}
用法用量（F列）: {F列データ}
年齢制限（G列）: {G列データ}
成分（H列）: {H列データ}
禁止物質（I列）: {I列データ}
競技会区分（J列）: {J列データ}
条件（K列）: {K列データ}

【生成する内容】
1. E列の効能効果を要約（1〜2文）
2. 使用してはいけない人（F列、G列、K列から抽出）
   - 年齢制限がある場合は必ず記載
   - その他の禁忌事項も記載

簡潔に2〜3行で記述してください。
"""
```

### データの流れ

```
CSVファイル（otc_medicine_data.csv）
    ↓
【候補薬取得】E〜K列すべてを取得
    ↓
【スコアリング】上位3件選出
    ↓
【個別の使用上の注意生成】
    各医薬品ごとに:
    ├─ ChatGPTでE〜K列から要約
    ├─ G列から年齢制限を抽出
    └─ フォーマット: "{i}つ目：{製品名}\n{要約}\n年齢制限: ..."
    ↓
【共通の使用上の注意追加】
    ├─ 使ってはいけない人（全体共通）
    └─ 服用時の注意（全体共通）
    ↓
【結合表示】
```
